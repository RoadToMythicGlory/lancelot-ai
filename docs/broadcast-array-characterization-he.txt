אפיון מערך השידורים ונגזרותיו - Lancelot AI
גרסה: 10.06.2026

מטרת המסמך
-----------
מסמך זה מתאר את אפיון מודול מערך השידורים (Broadcast Array) ואת כל שכבות העבודה הנגזרות ממנו:
דף ה-Grid השבועי, מודאל מערך שידורים מתוך התכנונית, ייבוא Excel, הגדרות טופס שיבוץ, חדרי בקרה משותפים,
אינטגרציה עם לוח טיסות, דאשבורד אישי, אזהרות זמינות משמרות וסטטוס השלמה בתכנונית.
המסמך מתמקד בדרישות עסקיות ותפעוליות בלבד.
הוא אינו כולל טכנולוגיות, שמות מערכות, שפות פיתוח, מבני קוד או פרטי מימוש.


1. מטרת מודול מערך השידורים
----------------------------
מערך השידורים הוא המודול שבו מתכננים ומשבצים את צוות השידור הפנימי לכל אירוע שידור.

הוא מיועד ל:

- שיבוץ אנשי צוות לתפקידים מוגדרים (עורך, מפיק, VTR, טכנאי/במאי, שדר, אנליסט, שדר קווים ועוד).
- בחירת מקום שידור / חדר בקרה לכל אירוע.
- הזנת הוראות מיוחדות לשידור.
- הוספת משימות דינמיות לפי מחלקות (תפקידים נוספים שמנהל המערכת מגדיר).
- עריכה מרוכזת בשבוע/חודש/יום — Grid בסגנון Excel.
- ייבוא שבועי מקובץ Excel "מערך שידורים" והתאמתו לאירועים קיימים בתכנונית.
- שיבוץ אנשי צוות חיצוניים (שאינם רשומים במערכת) בשם חופשי.
- הצגת השיבוצים בלוחות טיסות, בדאשבורד האישי ובסטטוס השלמת מחלקות בתכנונית.

מערך השידורים אינו יוצר אירועי שידור. מקור האמת לזמנים, ערוצים וכותרות — תכנונית השידורים.
מערך השידורים מוסיף על כל אירוע קיים את שכבת הצוות והמיקום התפעוליים.


2. עקרונות יסוד
---------------
- כל אירוע שידור נוצר בתכנונית. מערך השידורים עובד רק על אירועים שכבר קיימים שם.
- נתוני מערך השידורים נשמרים כמטא-דאטה של המחלקה `broadcastArray` תחת אותו אירוע.
- שני ממשקי עריכה — דף "מערך השידורים" ומודאל "מערך שידורים" בתכנונית — חולקים אותו מקור נתונים.
  שמירה באחד מהם משתקפת בשני לאחר רענון.
- שיבוץ במערך השידורים אינו יוצר משמרת אוטומטית במערכת השיבוצים — הוא תיעוד תפעולי בלבד.
  עם זאת, לפני שמירה — המערכת מזהירה אם לעובד פנימי יש חוסר זמינות בטווח האירוע.
- ניתן לסמן "לא עבורנו" — במקרה זה סטטוס ההשלמה בתכנונית נחשב מלא (ירוק).
- כל הממשק בעברית ובכיוון RTL.
- אזור זמן ברירת המחדל: Asia/Jerusalem.


3. ישות מרכזית: נתוני מערך שידורים לאירוע
-------------------------------------------

3.1 מיקום הנתונים
-----------------
לכל אירוע שידור, נתוני מערך השידורים נשמרים תחת:

`metadata.departments.broadcastArray`

(נתמך גם מפתח legacy: `broadcast-array` — לקריאה בלבד.)

3.2 שדות עיקריים
----------------

| שדה | תיאור | חובה לשלמות |
|-----|--------|-------------|
| crewAssignments | רשימת שיבוצי צוות — לכל רשומה: תפקיד, מזהה משתמש (אופציונלי), שם | כן — לפחות 6 שיבוצים לסטטוס "מלא" |
| מקוםשידור | חדר בקרה / מקום שידור — מתוך רשימה משותפת | כן — לסטטוס "מלא" |
| specialInstructions | הוראות מיוחדות / שם שידור תפעולי | לא |
| dynamicJobs | משימות נוספות לפי מחלקות (ראו סעיף 6) | לא |
| setupTime / breakdownTime | זמני הקמה / פירוק — שמורים לשימוש עתידי | לא |
| notApplicable | דגל "לא עבורנו" (ב-customData) | — |

3.3 מבנה crewAssignments
------------------------
כל שיבוץ הוא רשומה עם:

- role — שם התפקיד בעברית (למשל "עורך", "מפיק", "איש VTR").
- userId — מזהה משתמש פנימי (null עבור איש צוות חיצוני).
- userName — שם תצוגה (נגזר מהמשתמש או מוזן ידנית לחיצוני).

כל תפקיד תומך בשיבוץ מרובה — ניתן לבחור יותר מעובד אחד לאותו תפקיד.

3.4 שדות לקריאה בלבד (מתכנונית)
--------------------------------
במודאל מערך השידורים מוצגים שדות שמגיעים מהתכנונית ואינם ניתנים לעריכה שם:

- תאריך, יום, שעת שידור.
- משחק / כותרת האירוע.
- ערוץ.
- הערות כלליות מהתכנונית.

שינוי שדות אלה — רק דרך עריכת האירוע בתכנונית.


4. עמודות תפקידים (Role Columns)
---------------------------------

4.1 הגדרה
---------
עמודות ה-Grid ושדות השיבוץ במודאל נקבעות בהגדרות מערכת:
הגדרות → טפסי שיבוץ → "מערך שידורים" (AssignmentFormConfig, formKey: broadcastArray).

כל עמודה מגדירה:

- key — מזהה פנימי (למשל editor, producer).
- hebrewLabel — שם העמודה בעברית; גם הערך שנכתב ל-crewAssignments[].role.
- englishLabel — שם באנגלית (אופציונלי).
- allowedDepartmentCodes — מחלקות שממנה ניתן לבחור עובדים לעמודה.
- allowedUserIds — רשימת משתמשים ספציפיים (אופציונלי — דורס/משלים את המחלקות).
- order — סדר הצגה בעמודות.
- defaultCount — כמות ברירת מחדל (למשימות דינמיות).
- requireUser — האם חובה לשבץ משתמש (למשימות דינמיות).

4.2 עמודות ברירת מחדל (Fallback)
---------------------------------
אם לא הוגדרה תצורה — המערכת משתמשת בעמודות קבועות:

| עמודה | תפקיד (role) | מחלקות מקור עובדים (ברירת מחדל) |
|--------|--------------|-----------------------------------|
| עורך | עורך | עריכה, עורכי וידאו, עורכי ניו-מדיה, עורכי חדשות |
| מפיק | מפיק | הפקה, מפיקי ניו-מדיה, מפיקי חדשות |
| איש VTR | איש VTR | VTR, VTR הפקה |
| טכנאי / במאי | טכנאי שידור | במאים, במאי הפקה |
| שדר | שדר | פרשנים, פרשני הפקה |
| אנליסט | אנליסט | פרשנים, פרשני הפקה |
| שדר קווים | שדר קוים | סאונד, סאונדמני הפקה |

4.3 כללים
---------
- שינוי hebrewLabel בעמודה — משפיע על התאמה לנתונים קיימים; יש לשמור על יציבות.
- עמודות חדשות שהוגדרו על ידי מנהל — מופיעות ב-Grid ובמודאל לאחר רענון.
- עובד שאינו שייך יותר למחלקה הרלוונטית — מוצג כתג "חיצוני" (שם) ולא נעלם.


5. חדרי בקרה / מקום שידור
--------------------------

5.1 מקור הרשימה
---------------
רשימת חדרי הבקרה היא נתון עזר משותף (ExternalBroadcastReference, kind: controlRoom).
אותה רשימה משמשת גם:

- מערך השידורים (Grid + מודאל).
- שידורי חוץ (קונטרול משני בשידור כפול).
- MCR.
- דוחות שידורי חוץ.

5.2 ניהול הרשימה
-----------------
מנהל מערכת מוסיף / מעדכן / משבית חדרים ב:
הגדרות → נתוני עזר → חדרי בקרה.

שינוי ברשימה משתקף בכל המודולים ללא צורך בעדכון נפרד.

5.3 חדרי ברירת מחדל
-------------------
בהפעלת המערכת נטענים (אם לא קיימים):

קונטרול 1–8, יוניפייד 1–6, רדיו, יעלה לווין בלבד.

5.4 נרמול בייבוא Excel
----------------------
בקובץ Excel, ערכים כמו "חדר יוניפייד 5" מנורמלים ל-"יוניפייד 5";
"חדר רדיו" → "רדיו".


6. משימות דינמיות (Dynamic Jobs)
---------------------------------

6.1 מטרה
--------
לאפשר למנהל להגדיר תפקידים נוספים מעבר לעמודות הקבועות — למשל CG, טכנאי, MCR-General.

6.2 הגדרה
---------
בהגדרות טופס השיבוץ (broadcastArray) — מחלקות זמינות + תפקידים לכל מחלקה.
במודאל מערך השידורים — פאנל "משימות נוספות לפי הגדרות מחלקות".

6.3 שדות משימה
--------------
- departmentCode — קוד מחלקה.
- roleKey / roleLabel — תפקיד.
- count — כמות נדרשת.
- userId / userName — מי שובץ.

6.4 פריסטים
-----------
ניתן לשמור פריסטים משותפים לאירועים חוזרים (allowUserPresets: true).

6.5 הערה
--------
משימות דינמיות זמינות במודאל התכנונית. דף ה-Grid המרכזי מתמקד בעמודות התפקידים הקבועות.


7. אנשי צוות חיצוניים
----------------------

7.1 הגדרה
---------
עובד שאינו רשום במערכת — או שם שלא זוהה בייבוא Excel — נשמר כשם חופשי ללא userId.

7.2 בממשק Grid
--------------
- בתפריט בחירת עובד — שדה "שם של איש צוות חיצוני" + כפתור "חיצוני".
- תגית זהב מסמנת שיבוץ חיצוני (לעומת משתמש מערכת).

7.3 בייבוא Excel
----------------
שם שלא הותאם לרשימת העובדים — נשמר כחיצוני; המפעיל רואה אזהרה ברשימת "שמות שלא זוהו".

7.4 אזהרת זמינות
----------------
אזהרת חוסר זמינות (משמרות) — רק לעובדים פנימיים עם userId. חיצוניים — ללא בדיקה.


8. מסך מערך השידורים (Grid)
----------------------------

8.1 גישה
--------
- כניסה מהתפריט הצדדי: "מערך השידורים".
- הרשאת צפייה: BROADCAST_ARRAY_VIEW (מורש מ-BROADCAST_VIEW).
- עריכה / שמירה / ייבוא: BROADCAST_ARRAY_MANAGE (מורש מ-BROADCAST_MANAGE).

8.2 תצוגות זמן
--------------
- יומי — אירועי יום אחד.
- שבועי — ברירת מחדל; ראשון–שבת.
- חודשי — כל אירועי החודש.

ניווט: קודם / הבא / "היום" + בורר תאריך/שבוע/חודש.
תיאור טווח (למשל "שבוע 08/06 - 14/06/2026").

8.3 מבנה הטבלה
--------------
| עמודה | תוכן | עריכה |
|--------|------|--------|
| # | מספר שורה | לא |
| תאריך | מתכנונית | לא |
| שעה | מתכנונית | לא |
| אירוע | כותרת | לא |
| מקום שידור | חדר בקרה | כן |
| [עמודות תפקיד] | שיבוצי צוות | כן — בחירה מרובה |
| הוראות | specialInstructions | כן |
| פעולות | שמור שורה | — |

- טבלה ברוחב מלא, ללא גלילה אופקית — עמודות מתחלקות ביחס לרוחב המסך.
- שורה עם שינויים שלא נשמרו — רקע צהוב בהיר (dirty).

8.4 סרגל פעולות
---------------
- סינון — הצגה/הסתרת פאנל סינון.
- רענון — טעינה מחדש מהשרת.
- ייבוא מ-Excel — רק למשתמש עם הרשאת עריכה.
- שמור הכל — שמירת כל השורות המסומנות כ-dirty (עם מונה).

8.5 סינון וחיפוש
----------------
- חיפוש טקסט — כותרת, ערוץ, מקום שידור.
- סינון ערוץ — בחירה מרובה (רק ערוצים שמופיעים בטווח).
- סינון מקום שידור — בחירה מרובה.
- סינון לפי עובד — הצג אירועים שבהם העובד משובץ.
- סינון סטטוס שיבוץ:
  - הכל.
  - ללא שיבוץ — אף תפקיד לא מאויש.
  - מלא — כל התפקידים מאוישים.
  - חלקי — חלק מהתפקידים מאוישים.
  - שינויים לא שמורים — dirty בלבד.
- "נקה סינון" — איפוס כל המסננים.

8.6 שמירה
---------
- שמור שורה — שמירת אירוע בודד.
- שמור הכל — לולאה על כל השורות ה-dirty.
- לפני שמירה — בדיקת זמינות לעובדים פנימיים; אם יש חוסר — דיאלוג אישור/ביטול.
- הודעות: "השורה נשמרה" / "נשמרו N שורות, נכשלו M".


9. מודאל מערך שידורים (מתוך התכנונית)
---------------------------------------

9.1 גישה
--------
- בתכנונית → לחיצה על אירוע → "ניהול מחלקות" → לשונית "מערך שידורים".
- הרשאת עריכה: BROADCAST_MANAGE (כולל BROADCAST_ARRAY_MANAGE) + שיוך למחלקה רלוונטית.
- צפייה בלבד — תווית "לקריאה בלבד", ללא כפתורי שמירה.

9.2 תוכן
--------
- שדות לקריאה בלבד מהתכנונית (ראו 3.4).
- שם השידור (specialInstructions).
- מקום שידור — Select מרשימת חדרי בקרה.
- שיבוצי תפקידים — Select מרובה לכל תפקיד, מסונן לפי מחלקות.
- משימות דינמיות — פאנל DynamicDepartmentJobsPanel.
- כפתורים: ביטול | לא עבורנו | שמור.

9.3 "לא עבורנו"
---------------
שומר customData.notApplicable = true.
סטטוס מחלקה בתכנונית — ירוק (הושלם) ללא צורך בשיבוצים.


10. ייבוא Excel — מערך שידורים
--------------------------------

10.1 היקף
---------
ייבוא נפרד מייבוא התכנונית. לא יוצר אירועים חדשים — רק מעדכן שיבוצים ומיקום
לאירועים שכבר קיימים בתכנונית.

10.2 קובץ מקור
--------------
גיליון שבועי "מערך שידורים" — פורמט .xlsx / .xls.

10.3 מבנה עמודות צפוי (שורת כותרות)
------------------------------------
| כותרת בעברית | תוכן |
|---------------|------|
| יום | יום בשבוע (מידע בלבד) |
| תאריך | תאריך האירוע |
| שעת שידור / שעה | שעת התחלה |
| שידור | ליגה / סוג שידור |
| משחק | פרטי משחק (זמן בסוגריים מוסר) |
| ערוץ | ערוץ — עברית או אנגלית |
| מקום שידור | חדר בקרה |
| עורך | שמות — מרובים מופרדים |
| מפיק | שמות |
| איש VTR (ריפליי) / איש VTR / VTR | שמות |
| טכנאי שידור / במאי / טכנאי / במאי | שמות |
| שדר + פרשן / שדר ופרשן / שדר | שדר + אנליסט (פיצול חכם) |
| שדר קוים / שדר קווים | שמות |
| הערות | הוראות מיוחדות |

10.4 תהליך
----------
1. העלאת קובץ.
2. פרסור בשרת — החזרת שורות מובנות + שגיאות (שורות ריקות/לא תקינות).
3. שליפת אירועי התכנונית בטווח התאריכים של הקובץ.
4. התאמה אוטומטית לכל שורה — לפי ערוץ + תאריך + שעה (±30 דק') + דמיון כותרת.
5. תצוגת סקירה — סטטוס לכל שורה:
   - תואם (MATCHED) — התאמה ברורה.
   - מספר התאמות (AMBIGUOUS) — יש לבחור אירוע ידנית.
   - לא נמצא (UNMATCHED) — אין אירוע מתאים; ניתן לבחור ידנית או לדלג.
6. התאמת שמות לעובדים — fuzzy match; כישלון → שם חיצוני.
7. סימון שורות ליישום (checkbox).
8. יישום — שמירה לכל שורה שנבחרה (אותה מutation כמו Grid).
9. סיכום — N הצליחו, M נכשלו.

10.5 נרמול ערוצים בייבוא
------------------------
5 SPORT → CHANNEL 1, 5 LIVE → CHANNEL 4, 5 PLUS → CHANNEL 2,
5 STARS → CHANNEL 5, 5 GOLD → CHANNEL 3, 4K → CHANNEL 1 4K, MAX → CHANNEL 6.

10.6 קשר לייבוא התכנונית
-------------------------
בייבוא Excel לתכנונית — עמודות עורך/מפיק/VTR/טכנאי/שדר/קווים מסווגות אוטומטית
למחלקת מערך שידורים (מילות מפתח: שידור, מערך, עורך, מפיק, טכנאי, שדר, קוים).
זהו ייבוא נפרד — משלים את ייבוא מערך השידורים השבועי.


11. סטטוס השלמת מחלקה (בתכנונית)
----------------------------------

11.1 קריטריונים — מערך שידורים
-------------------------------
- מלא (ירוק): לפחות 6 שיבוצי צוות + מקום שידור / שדה שידור; או "לא עבורנו".
- חלקי (כתום): יש שיבוצים או שדות חלקיים.
- ריק (אפור/אדום): אין נתונים.

11.2 הצגה
---------
- אייקון סטטוס מחלקה על כרטיס האירוע בלוח התכנונית.
- סינון מתקנונית לפי סטטוס מחלקות (מלא / חלקי / ריק).
- צביעת שורות — חלק מלוגיקת "השלמת כל המחלקות" (ירוק/צהוב).


12. נגזרת: אינטגרציה עם תכנונית השידורים
------------------------------------------

12.1 תלות
---------
מערך השידורים תלוי באירועים מהתכנונית. ללא אירוע — אין שורה ב-Grid.

12.2 דיאלוג ניהול מחלקות
-------------------------
מערך שידורים הוא אחת מ-7 לשוניות:
מערך שידורים | MCR | שידורי חוץ | כתוביות | מחסן | שידורי לוויין | Rundown.

12.3 עדכון אירוע
----------------
שינוי כותרת/שעה/ערוץ בתכנונית — משתקף ב-Grid לאחר רענון.
שיבוצי מערך — לא נמחקים אוטומטית בשינוי שעה.


13. נגזרת: לוח טיסות (Flight Board)
-------------------------------------

13.1 מטרה
---------
הצגת צוות מערך השידורים על מסכים גדולים בחדרי בקרה.

13.2 נתונים זמינים לפאנל
-------------------------
מכל אירוע — אם קיים broadcastArray:

- broadcastLocation — מקום שידור.
- specialInstructions — הוראות.
- byRole — מילון תפקיד → רשימת שמות.
- summary — רשימה מלאה.
- שדות מפורקים: editor, producer, vtr, broadcastTech, anchor, analyst, sidelineAnchor.

13.3 שורות ידניות
-----------------
ניתן להוסיף שורות ידניות בלוח עם override לשדות מערך (למשל raw.broadcastArray.broadcastLocation).
ערך "יעלה לווין בלבד" — שימוש מיוחד לסינון/תצוגה בלוח MCR.

13.4 רענון
---------
שינוי במערך השידורים — משתקף בלוח לאחר רענון / polling.


14. נגזרת: דאשבורד אישי
-------------------------

14.1 "העבודה שלי"
-----------------
בדאשבורד — רשימת משמרות + שיבוצי מערך שידורים ל-7 הימים הקרובים.

14.2 חילוץ שיבוצים
------------------
- סריקת crewAssignments בכל אירוע.
- סינון לפי userId של המשתמש המחובר.
- הצגה: תפקיד, אירוע, שעות, מקום שידור.

14.3 מיון
---------
מיזוג עם משמרות — מיון לפי זמן התחלה.


15. נגזרת: אזהרות זמינות (משמרות)
-----------------------------------

15.1 מתי
--------
לפני שמירת שיבוץ — Grid, מודאל, וייבוא Excel (עבור עובדים פנימיים).

15.2 התנהגות
------------
- אם לעובד סומנה חוסר זמינות בטווח האירוע — דיאלוג אזהרה.
- המפעיל יכול לאשר ולשמור בכל זאת, או לבטל.
- אין חסימה אוטומטית — אזהרה בלבד.

15.3 הערה
---------
חפיפת ערוץ (בתכנונית) ≠ חפיפת צוות. מערך השידורים לא בודק חפיפת צוות אוטומטית.


16. נגזרת: הגדרות מערכת
-------------------------

16.1 טופס שיבוץ — מערך שידורים
-------------------------------
הגדרות → טפסי שיבוץ → מערך שידורים:

- עמודות Grid (columns) — סדר, תוויות, מחלקות מותרות.
- מחלקות למשימות דינמיות (departments).
- allowUserPresets — פריסטים משותפים.

16.2 חדרי בקרה
--------------
הגדרות → נתוני עזר → חדרי בקרה — רשימה משותפת (ראו סעיף 5).

16.3 הרשאות מהירות למשתמשים
----------------------------
במסך משתמשים — קיצור דרך להוספת הרשאות מערך שידורים נפוצות.


17. הרשאות
----------

| פעולה | הרשאה | הערות |
|-------|--------|--------|
| צפייה בדף מערך השידורים | BROADCAST_ARRAY_VIEW | מורש אוטומטית מ-BROADCAST_VIEW |
| עריכה / שמירה / ייבוא Excel | BROADCAST_ARRAY_MANAGE | מורש מ-BROADCAST_MANAGE |
| צפייה במודאל מתכנונית | BROADCAST_VIEW | |
| עריכה במודאל מתכנונית | BROADCAST_MANAGE | |
| ניהול הגדרות טופס | SETTINGS_MANAGE | |
| ניהול חדרי בקרה | SETTINGS_MANAGE + מסך נתוני עזר | |

SYSTEM_ADMIN / IT_ADMIN — גישה מלאה.


18. זרימות עבודה עיקריות
-------------------------

18.1 זרימה: שבוע שידורים חדש
----------------------------
1. צוות התכנון מייבא/יוצר אירועים בתכנונית.
2. מנהל מערך מקבל גיליון Excel שבועי "מערך שידורים".
3. ייבוא Excel בדף מערך השידורים → סקירה → יישום.
4. תיקון ידני של שורות AMBIGUOUS / UNMATCHED.
5. שמירה — Grid או "שמור הכל".
6. צוות רואה שיבוצים בדאשבורד; חדר בקרה — בלוח טיסות.

18.2 זרימה: שיבוץ ידני לאירוע בודד
----------------------------------
1. תכנונית → אירוע → מערך שידורים.
2. בחירת חדר + צוות + משימות דינמיות.
3. אישור אזהרת זמינות (אם יש).
4. שמור — סטטוס מחלקה מתעדכן בתכנונית.

18.3 זרימה: אירוע לא רלוונטי למערך
-----------------------------------
1. מודאל מערך שידורים → "לא עבורנו".
2. סטטוס ירוק בתכנונית — ללא שיבוצים.

18.4 זרימה: עדכון שעת משחק
---------------------------
1. עריכה בתכנונית.
2. Grid מציג שעה מעודכנת לאחר רענון.
3. שיבוצים קיימים נשמרים — מומלץ לוודא זמינות מחדש.


19. אינטגרציות בין מודולים
---------------------------

| מקור | יעד | מה מסתנכרן |
|------|-----|-------------|
| תכנונית | מערך Grid | אירועים, כותרות, שעות, ערוצים |
| מערך שידורים | תכנונית | סטטוס השלמת מחלקה, מטא-דאטה |
| מערך שידורים | לוח טיסות | צוות, מיקום, הוראות |
| מערך שידורים | דאשבורד | "העבודה שלי" — שיבוצים אישיים |
| מערך שידורים | משמרות | אזהרת זמינות (לא שיבוץ אוטומטי) |
| Excel מערך | מערך שידורים | crewAssignments + מקום + הערות |
| Excel תכנונית | מערך (עמודות צוות) | נתונים ראשוניים ב-metadata |
| הגדרות חדרי בקרה | מערך + MCR + שידורי חוץ | רשימת מקום שידור |
| AssignmentFormConfig | Grid + מודאל | עמודות ומשימות דינמיות |

מה שאינו מסתנכרן אוטומטית:
- שידורי חוץ — צוות הפקה שטח נפרד; שיבוץ מערך ≠ שיבוץ שידורי חוץ.
- משמרות — שיבוץ במערך לא יוצר משמרת.


20. נואנסים חשובים
----------------------

- מקור האמת לזמנים וערוצים — תכנונית; מערך שידורים לא משנה אותם.
- שני ממשקים, מקור נתונים אחד — Grid ומודאל; חובה לרענן אחרי שמירה במקביל.
- תפקיד "אנליסט" ו"שדר" — באותה מחלקת פרשנים; בייבוא Excel עמודת "שדר + פרשן" מפוצלת חכם.
- עמודות "שדר קוים" ו"שדר קווים" ב-Excel — מאוחדות לתפקיד "שדר קוים".
- שמות legacy בעברית (שידור, מקוםשידור) — נתמכים לקריאה; שמירה חדשה בפורמט מאוחד.
- dynamicJobs — רק במודאל; לא ב-Grid המרכזי.
- ייבוא Excel לא יוצר אירועים — חייבים קודם תכנונית.
- סף התאמת אירוע: ציון ≥ 0.55; פער < 0.1 בין מועמדים → AMBIGUOUS.
- התאמת שם: exact → tokens → similarity ≥ 0.75.


21. הודעות למשתמש
-----------------

שמירה:
- "השורה נשמרה".
- "נשמרו N שורות, נכשלו M".
- "נתוני מערך השידורים נשמרו בהצלחה".

שגיאות:
- "אין לך הרשאת עריכה".
- "שמירה נכשלה: [סיבה]".

Grid:
- "אין אירועים בטווח התאריכים שנבחר".
- "אין שורות התואמות את הסינון הנוכחי".

ייבוא:
- "הקובץ נטען אך לא נמצאו שורות תקפות".
- "עיבוד הקובץ נכשל".
- "שליפת אירועים מהמערכת נכשלה".

זמינות:
- דיאלוג: עובד/ים סימנו חוסר זמינות — האם להמשיך?

"לא עבורנו":
- "לא רלוונטי לנו — נשמר".


22. מסכים ותתי-מסכים — סיכום
-----------------------------

| מסך / רכיב | נגישות | תפקיד |
|------------|--------|--------|
| מערך השידורים (Grid) | תפריט ראשי | עריכה שבועית/חודשית מרוכזת |

| חדרי בקרה | הגדרות → נתוני עזר | רשימה משותפת |
| לוח טיסות | תפריט / MCR | תצוגת צוות על מסך |
| דאשבורד | דף הבית | שיבוצים אישיים |
