זרימות עבודה חוצות-מודולים — Lancelot AI
גרסה: 10.06.2026


1. זרימה: משחק חדש מ-Excel
----------------------------
1. צוות התכנון מקבל גיליון Excel מהליגה.
2. ייבוא לתכנונית → תצוגה מקדימה → אישור.
3. אירועים נוצרים + Shadow MCR לכל אירוע.
4. מערך שידורים — שיבוץ צוות (Grid או מודאל).
5. MCR — מילוי מקור/גיבוי/ניתובים.
6. שידורי חוץ — ייבוא רלוונטי + מילוי הפקה.
7. מחסן — הקצאת ציוד.
8. כתוביות — בחירת CC/שפת סימנים.
9. לוח טיסות — תצוגה מרוכזת.


2. זרימה: עדכון שעת משחק
-------------------------
1. עריכת אירוע בתכנונית (שעה / KO).
2. בדיקת חפיפה.
3. סנכרון אוטומטי ל-MCR Shadow + שורת לו"ז.
4. עדכון: תכנונית, MCR, לוח טיסות.


3. זרימה: ביטול שידור
-----------------------
1. שינוי סטטוס / מחיקה בתכנונית.
2. שידורי חוץ — סימון "בוטל" (assignmentStatus).
3. מחסן — החזרת ציוד שהוקצה.
4. MCR — עדכון סטטוס שורת לו"ז.


4. מפת סנכרון בין מודולים
--------------------------

| מקור | יעד | מה מסתנכרן |
|------|-----|-------------|
| תכנונית | MCR | כותרת, שעות, ערוץ → Shadow + ActivityRow |
| תכנונית | שידורי חוץ | ייבוא מפורש בלבד |
| תכנונית | מחסן | בקשות + הקצאות (הקצאה = תהליך מחסן) |
| תכנונית | לוח טיסות | תצוגה לפי פאנלים |
| מערך שידורים | משמרות | אזהרת זמינות (לא שיבוץ) |
| Excel | כל המחלקות | עמודות לא ממופות → מחלקות לפי מילות מפתח |
| מחסן | MCR | ציוד הנדסה שיתופי |
| מחסן | שידורי חוץ | דיווח תקלות |


5. נואנסים חוצי-מודולים
------------------------
- התכנונית = מקור אמת לזמנים וערוצים; MCR יכול זמני MCR נפרדים.
- שידורי חוץ לא רואים אירוע עד ייבוא מפורש.
- סטטוס מחלקה בתכנונית ≠ סטטוס שיבוץ תפעולי בשידורי חוץ.
- חפיפת ערוץ ≠ חפיפת צוות.
- מחיקת אירוע — הקצאות ציוד פעילות חוסמות.
- חדרי בקרה — רשימה משותפת (נתוני עזר) לכל המודולים.
