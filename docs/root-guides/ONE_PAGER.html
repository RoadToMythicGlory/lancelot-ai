What It Solves

  • Centralized planning — replaces fragmented spreadsheets and manual scheduling with a single source of truth.
  • Deterministic scheduling — conflict / overlap detection on every event creation and Excel import.
  • Real-time coordination — GraphQL subscriptions push updates instantly to every operator's screen.

Architecture Overview

Tech Stack

Frontend: Next.js 15, React 18, TypeScript, Apollo Client, graphql-ws, Socket.IO Client, Ant Design + Tailwind

Backend: Node.js + Express, Apollo Server (GraphQL), graphql-ws subscriptions, Socket.IO chat server

Data: MongoDB 7 (sole runtime datastore for all collections)

AI / LLM: Ollama local inference (GGUF models), optional llama.cpp, Zod schema validation, OR-Tools constraint solver

Infra: Docker Compose, optional Redis (rate limiting), Turbo monorepo

Security & Privacy

  • JWT authentication — login mutation issues a signed token; every request is verified via context builder.
  • bcrypt password hashing — salted hashes; no plaintext storage.
  • CORS allowlist — configurable origin restrictions.
  • Rate limiting — production-ready, with optional Redis backend.
  • End-to-end encryption (E2EE) — chat encryption enabled by default in non-prod; progressive rollout in production via ENABLE_E2EE_CHAT flag. AI agent participates via crypto keys.
  • On-prem / offline-first AI — all LLM inference runs locally via Ollama. No data leaves the network; no cloud LLM APIs.

Developer Quickstart

# Prerequisites: Node.js 18+, MongoDB, Ollama running on localhost:11434

# Install & start Web UI + API Gateway (Windows)
npm install
npm run dev:windows

# In separate terminals:
cd services/excel-parser && npm install && npm run dev   # Excel Parser
cd services/ai-agent    && npm install && npm run dev   # AI Agent
cd services/ai-agent    && npm run seed:ai-user          # Seed AI user in MongoDB

Environment files: apps/web/.env.local · services/api-gateway/.env · services/excel-parser/.env · services/ai-agent/.env
