# מדריך משתמש מלא - מערכת Lancelot

> **המדריך הזה מתעד כל מסך, כל לחצן, וכל פעולה במערכת Lancelot AI - מערכת ניהול תפעולי השידור (Broadcast Operations Platform).**
> הוא נכתב למשתמשים מתחילים לחלוטין: גם מי שלא ראה את המערכת מעולם אמור להצליח לבצע כל פעולה בעזרת המדריך.
>
> המדריך זמין בשני מקומות: כקבצי Markdown בתיקייה `docs/user-manual/` (לקריאה ב-Git), וגם בתוך האפליקציה בעמוד **עזרה** (`/help`) - מסוכרן אוטומטית על ידי הסקריפט `npm run seed:help`.

### הודעות מערכת (Toast)

הודעות קצרות שמופיעות בפינה הימנית-עליונה למשך 4 שניות:

- **רקע ירוק** - הצלחה (לדוגמה: "נשמר בהצלחה").
- **רקע אדום** - שגיאה (לדוגמה: "שגיאה בשמירת המשתמש").
- **רקע אפור-כהה** - מידע רגיל.

## מילון מונחים בסיסי

| מונח | משמעות |
|------|---------|
| **תכנונית** | התכנון השבועי/חודשי של אירועי שידור (Broadcast Planning). |
| **MCR** | Master Control Room - חדר הבקרה הראשי, האחראי על שידור בפועל. |
| **אירוע שידור** (Broadcast Event) | פריט בודד בלוח השידורים: משחק, תוכנית, חדשות וכו'. |
| **שידור חוץ** (External Broadcast) | הפקה שמבוצעת מחוץ לאולפן - דורשת צוות וציוד נוסף. |
| **ברקוד ציוד** | מזהה ייחודי שמודבק על כל פריט ציוד פיזי במחסן. |
| **DAM** | Digital Asset Management - ניהול נכסי דיגיטל. |
| **Workflow** | תהליך אוטומטי של אישורים והעברות בין משתמשים. |
| **Webhook** | התראה אוטומטית שנשלחת למערכת חיצונית כשמשהו קורה. |
| **Permission** | הרשאה לפעולה ספציפית (כמו `WAREHOUSE_MANAGE`). |
| **System Role** | תפקיד מערכת ראשי - מנהל מערכת, מנהל IT, וכו'. |
| **Department** | מחלקה - קבוצת משתמשים שעובדים יחד (MCR, מחסן, חדשות, וכו'). |
| **SLA** | Service Level Agreement - דד-ליין לתהליך אישור. |
| **MFA** | Multi-Factor Authentication - אימות דו-שלבי. |
| **SSO** | Single Sign-On - כניסה חד-פעמית (כמו עם חשבון Google הארגוני). |

## דרכי קריאה מומלצות

- **משתמש חדש?** קראו את 01 → 02 → המודול שאתם הולכים להשתמש בו (לדוגמה 08 לעובדי מחסן).
- **מנהל מערכת חדש?** קראו 01 → 03 → 13 → 20 בסדר הזה.
- **משתמש קיים עם בעיה?** קפצו ל-19 (פתרון בעיות) או חפשו במאמרים בתוך `/help`.

## איך לקרוא את המדריך בתוך האפליקציה

1. התחברו ל-Lancelot.
2. בסיידבר הימני, גללו למטה לסעיף **מערכת** ולחצו על **עזרה**.
3. בלשונית **מאמרי עזרה** תראו את כל הכרטיסים של המאמרים.
4. אפשר לחפש בשורת החיפוש או לסנן לפי קטגוריה.
5. לחצו על כרטיס כדי לפתוח את המאמר במלואו.

אם המאמרים לא מופיעים, ייתכן שלא הורצה הזריעה. ראו `18-help-support.md`.
