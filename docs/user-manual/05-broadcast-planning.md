# תכנונית שידורים - יצירת אירועי שידור, יבוא Excel ועריכה לפי מחלקות

> **התכנונית (Broadcast Planning) היא המסך המרכזי לתכנון של אירועי השידור: משחקים, תוכניות, חדשות, וכל מה ששודר בערוצים שלכם.**
> כאן יוצרים אירוע חדש (ידני או ביבוא Excel), עורכים אותו לפי מחלקות (MCR, שידורי חוץ, מחסן, וכו'), בודקים חפיפות ערוץ, וצופים בלוח הזמנים בתצוגות יומית/שבועית/חודשית.

---

## מתי משתמשים בזה?

- כשרוצים להוסיף משחק / תוכנית חדשה ללוח השידורים.
- כשמקבלים גיליון Excel מצוות התכנון של הספורט - כדי לייבא את כל השידורים בבת אחת.
- כדי לעדכן פרטי מחלקה לאירוע (לדוגמה: לקבוע את הצוות, להזין הערות MCR).
- כדי לראות אם יש חפיפה בערוץ (שני שידורים חיים באותו ערוץ באותו זמן).
- כדי לסנן ולחפש אירועי שידור.

## איך נכנסים?

1. בסיידבר, לחצו על **תכנונית** (אייקון לוח שנה).
2. תועברו ל-`/broadcast-planning`.

הרשאה נדרשת: `BROADCAST_VIEW`.

## מסכים ותתי-מסכים

### 1. סרגל ניווט עליון

מלמעלה למטה ומימין לשמאל:

- **כפתורי תצוגה**: יומי / שבועי / חודשי.
- **כפתורי ניווט תאריך**: 
  - **חץ ימינה (`<`)** - שבוע/יום/חודש קודם.
  - **חץ שמאלה (`>`)** - הבא.
  - **"היום"** - חזרה לתאריך הנוכחי.
  - **תיאור התקופה** - לדוגמה "שבוע 7, 12-18/02/2026".

### 2. סרגל פעולות

- **+ צור אירוע ספורט** (כפתור כחול ראשי) - יוצר אירוע ספורט בודד.
- **ייבוא מקובץ** - יבוא של Excel.
- **יצירה מרובה (Batch)** - יצירת אירועים חוזרים (כל יום, כל שבוע).
- **רענן** (אייקון חצים) - טוען מחדש מהשרת.

### 3. שורת חיפוש וסינון

- **שדה חיפוש** - הקלידו שם של אירוע, קבוצה, ספורט, או ליגה.
- **סינון מתקדם** - פותח חלון Drawer עם פילטרים:
  - ערוצים (multi-select)
  - ענפים (כדורגל, כדורסל, וכו')
  - ליגות
  - קבוצות
  - סוגי אירוע (חי / מוקלט)
  - סטטוס מחלקות (מלא / חלקי / ריק)
  - טווח זמנים
  - 4K כן/לא
  - ערוץ מקביל כן/לא
- **נקה סינון** - מנקה את כל הפילטרים.
- **תבניות סינון מוגדרות מראש** (Presets):
  - "שידורים חיים"
  - "כדורגל בלבד"
  - "ערוץ CHANNEL 1"
  - "שידורי 4K"

### 4. הלוח (התצוגה הראשית)

**במצב שבועי / חודשי**: לוח שנה עם תאים. בכל תא - האירועים של היום, צבועים לפי ערוץ / סוג.

**במצב יומי**: רשימת אירועים מסודרים לפי שעה.

**לכל אירוע על הלוח**:
- כותרת.
- שעה.
- ערוץ (תגית צבעונית).
- אייקונים מהירים: סטטוס מחלקות, חי/מוקלט, 4K.
- **לחיצה ימנית / 3 נקודות** פותחת תפריט:
  - **ניהול מחלקות** - פותח דיאלוג עם 6 הלשוניות לכל מחלקה.
  - **עריכת אירוע** - פותח טופס עריכה.
  - **מחיקה** - מחיקה (דורש אישור).

### 5. סטטוס מחלקות (לכל אירוע)

כל אירוע מצריך מילוי על ידי 6 מחלקות:

| מחלקה | מה היא ממלאת |
|--------|----------------|
| **מערך שידור** (broadcastArray) | צוות (במאי, צלמים, פרשנים, וכו'), מיקום, ציוד, ערכת קוים |
| **MCR** | מקור, גיבוי, ניתובים, סוג שידור (SRT/DVBS2/וכו') |
| **שידורי חוץ** (externalBroadcasts) | הפקה, צוות, ציוד נדרש |
| **כתוביות** (closedCaptions) | תרגום, נגישות, סנכרון |
| **מחסן** (warehouse) | ציוד ספציפי שיצא לאירוע |
| **פלייאאוט** (playout) | קליטה, GMT, סינופסיס, שידור חוזר |

לכל מחלקה - אייקון בכרטיס האירוע מסומן:
- **ירוק** - הושלם.
- **כתום** - חלקי.
- **אפור** - ריק.

## כל פעולה צעד-אחר-צעד

### פעולה 1: יצירת אירוע ספורט בודד

**מסך:** כפתור "+ צור אירוע ספורט" בסרגל הפעולות.

**צעדים:**

1. לחצו על **+ צור אירוע ספורט**.
2. ייפתח חלון "יצירת אירוע שידור ספורט".
3. מלאו את השדות:

#### חלק עליון - בסיסי

- **ספורט** (חובה) - הקלידו או בחרו: "כדורגל", "כדורסל", "טניס" וכו'.
- **ליגה / תחרות** (חובה) - "ליגת העל", "NBA", "ליגת האלופות"...
- **שלב** (אופציונלי) - "חצי גמר", "גמר", "מחזור 10".

#### קבוצות

- **קבוצה מארחת** (חובה) - שם הקבוצה.
- **קבוצה אורחת** (חובה).

#### זמנים

- **תאריך** (חובה) - בחרו מהלוח.
- **שעת התחלה** (חובה) - HH:MM.
- **שעת סיום** (חובה) - HH:MM (אוטומטית 2 שעות אחרי ההתחלה, ניתן לשנות).
- **שעת KO (Kick-off / Tip-off)** (אופציונלי) - שעת המשחק עצמו (לרוב 5-15 דקות אחרי תחילת השידור).

#### ערוץ ועוד

- **ערוץ** (חובה) - בחרו: CHANNEL 1 / CHANNEL 4 / CHANNEL 2 / CHANNEL 5 / CHANNEL 3 / CHANNEL 1 4K.
- **ערוץ מקביל** (אופציונלי) - אם השידור עובר במקביל בערוץ נוסף.
- **שידור חי** (כן/לא, ברירת מחדל כן).
- **שידור ב-4K** (כן/לא).
- **כתוביות נדרשות** (כן/לא).

#### כותרת והערות

- **כותרת** (אופציונלי) - אם משאירים ריק, נוצר אוטומטית מהקבוצות. לדוגמה "מכבי תל אביב נגד הפועל באר שבע".
- **הערות** - טקסט חופשי.

#### כפתורים בתחתית

- **צור אירוע** (כחול) - יוצר את האירוע.
- **בטל** - סוגר את החלון.

**אחרי לחיצה על "צור אירוע":**

המערכת בודקת **חפיפת ערוץ אוטומטית**:

- אם אין חפיפה - האירוע נוצר. הודעה ירוקה "האירוע נוצר בהצלחה".
- אם יש חפיפה - יוצג דיאלוג אזהרה עם רשימת השידורים שמתנגשים. תוכלו:
  - **לבטל** - לא ליצור.
  - **ליצור בכל זאת** - אזהרה רק, לא חוסם.
  - **לשנות ערוץ** - לחזור לטופס.

### פעולה 2: יבוא אירועים מקובץ Excel

**מסך:** כפתור "ייבוא מקובץ" בסרגל הפעולות.

**צעדים:**

1. לחצו **ייבוא מקובץ**.
2. ייפתח דיאלוג "בחר שיטת יצירה" - בחרו "ייבוא מ-Excel".
3. ייפתח חלון העלאה. גררו או בחרו קובץ `.xlsx` או `.xls`.
4. הקובץ נשלח לשרת `excel-parser` (`POST /parse-broadcast-schedule`).

#### מה הפרסר מצפה לראות?

הקובץ צריך להיות מסודר כך:
- שורה ראשונה - כותרות בעברית.
- כל שורה - אירוע אחד.

המיפויים האוטומטיים של הכותרות בעברית לשדות:

| כותרת בעברית | שדה |
|---------------|------|
| שעה / שעת שידור | שעת התחלה |
| תאריך | תאריך |
| ערוץ | ערוץ |
| סוג | סוג אירוע |
| אירוע / שידור | שם אירוע |
| מיקום / מקום שידור | מיקום |
| הערות | הערות |
| יום | יום בשבוע |
| שבוע | מספר שבוע |
| KO / TO | שעת Kick-off |
| ענף | ספורט |
| ליגה/ענף / ליגה/תחרות | ליגה |
| שלב | שלב |
| מארחת / מאירח | קבוצה מארחת |
| אורחת | קבוצה אורחת |
| ישיר | חי (כן/לא) |
| סיום | שעת סיום |
| כ"ס / פטיליות | כתוביות |
| ערוץ מקביל | ערוץ מקביל |
| 5 SPORT 4K / CHANNEL 1 4K | 4K |
| משחק | שם משחק |
| עורך | עורך |
| מפיק | מפיק |
| איש VTR (ריפליי) | VTR |
| טכנאי שידור / במאי | במאי טכני |
| שדר + פרשן | פרשנים |
| שדר קוים | פרשן קוים |

**ערוצים מומרים אוטומטית מאנגלית לעברית:**

| באנגלית | בעברית |
|---------|--------|
| 5 SPORT / CHANNEL1 | CHANNEL 1 |
| 5 LIVE / SPORT LIVE | CHANNEL 4 |
| 5 PLUS / SPORT PLUS | CHANNEL 2 |
| 5 STARS | CHANNEL 5 |
| 5 GOLD | CHANNEL 3 |
| 5 SPORT 4K | CHANNEL 1 4K |

**עמודות שאין להן מיפוי קבוע** נשמרות תחת `metadata.rawHebrewData` ומסווגות לפי מילות מפתח למחלקות:
- "שידור, מערך, עורך, מפיק" → broadcastArray
- "מקור, גיבוי, ניתובים, MCR" → mcr
- "הפקה, צוות, ציוד, חוץ" → externalBroadcasts
- "כתוביות, נגישות" → closedCaptions
- "מחסן, ברקוד" → warehouse
- "קליטה, GMT, פלייאאוט" → playout

5. אחרי הפרסור - תוצג רשימה של האירועים שנמצאו בקובץ.
6. סקרו את הרשימה - וודאו שהכל נכון.
7. שורות עם שגיאה (חסר תאריך/שעה) יוסרו אוטומטית - תופיע התראה כמה הוסרו.
8. לחצו **"צור הכל"** או **"צור אירועים נבחרים"**.
9. המערכת בודקת חפיפות לכל אירוע ויוצרת אותם.
10. בסוף: "נוצרו N אירועים. M אירועים נכשלו (עם רשימת הסיבות)."

**אם יש שגיאות בקובץ:**
- ודאו ששורה 1 מכילה כותרות.
- ודאו שעמודות "תאריך" ו-"שעה" קיימות וממולאות.
- פורמט תאריך מומלץ: DD/MM/YYYY.
- פורמט שעה מומלץ: HH:MM.

### פעולה 3: יצירה מרובה (Batch)

**מסך:** כפתור "יצירה מרובה" בסרגל הפעולות.

**צעדים:**

1. לחצו **יצירה מרובה**.
2. ייפתח טופס:
   - **בסיס האירוע** - שם, ספורט, ליגה, ערוץ.
   - **תאריך התחלה** + **תאריך סיום**.
   - **תדירות**: כל יום / כל שבוע ביום מסוים / חודשי.
   - **שעה קבועה**.
3. לחצו **צור**.
4. המערכת תיצור את כל האירועים בטווח.

שימוש לדוגמה: סדרת תוכניות יומית בערוץ.

### פעולה 4: עריכת מחלקה לאירוע

**מסך:** לחיצה על אירוע על הלוח → תפריט נקודות → "ניהול מחלקות".

**צעדים:**

1. לחצו על אירוע - יופיע תפריט קצר.
2. לחצו **ניהול מחלקות**.
3. ייפתח חלון רחב עם 6 לשוניות, אחת לכל מחלקה.
4. **לכל לשונית - מומלץ למלא או לדחות:**
   - **מערך שידור** (broadcastArray):
     - מקום שידור (אולפן/אצטדיון).
     - **שיבוצי צוות** (crewAssignments) - להוסיף משתמשים עם תפקיד (במאי, צלם, פרשן).
     - ציוד שדה.
     - הערות פרשנים.
   - **MCR**:
     - סוג שידור (SRT CALLER / SRT LISTENER / DVBS2 / NS3 / NS4 / RTMP / ZIXI / PRT / LIVEU / OTHER).
     - מקור (IP/Port אם רלוונטי).
     - גיבוי.
     - ניתובים.
     - העלאת מערך לוויני (PDF/Word).
     - הערות.
   - **שידורי חוץ** (externalBroadcasts):
     - בקשת הפקה.
     - צוות חיצוני.
     - ציוד נוסף.
   - **כתוביות**:
     - שפת תרגום.
     - שמיעת לקויי שמיעה.
     - סנכרון.
   - **מחסן** (warehouse):
     - **רשימת ציוד שצריך לצאת** + ברקודים.
     - המחסן יקצה אוטומטית בעת סריקה.
   - **פלייאאוט**:
     - מקור הקליטה (GMT, שעת התחלת קליטה).
     - סינופסיס.
     - שידור חוזר (כן/לא, תאריך).
5. לחצו **שמור** בכל לשונית (או "שמור הכל" אם קיים).
6. הסטטוס של המחלקה ישתנה: אפור → כתום (חלקי) או ירוק (מלא).

### פעולה 5: עריכת אירוע קיים (פרטי בסיס)

**מסך:** תפריט נקודות → "עריכת אירוע".

**צעדים:**

1. ייפתח חלון "עריכת אירוע שידור ספורט" - זהה לטופס היצירה אבל עם הערכים הקיימים.
2. שנו את מה שצריך.
3. לחצו **שמור שינויים**.
4. אם שינוי שעה/ערוץ יוצר חפיפה - תוצג אזהרה.

### פעולה 6: מחיקת אירוע

**מסך:** תפריט נקודות → "מחיקה".

**צעדים:**

1. לחצו **מחיקה**.
2. ייפתח דיאלוג: "האם אתה בטוח שברצונך למחוק את האירוע?".
3. לחצו **כן, מחק** או **בטל**.
4. אם נמחק - "האירוע נמחק". אם הייתה תלות בנתוני מחלקה - הם גם נמחקים.

**הרשאה נדרשת:** `BROADCAST_DELETE`.

### פעולה 7: חיפוש וסינון

**מסך:** סרגל החיפוש + כפתור "סינון מתקדם".

**צעדים:**

1. **חיפוש מהיר** - הקלידו בשדה החיפוש; הלוח יסתנן בזמן אמת.
2. **סינון מתקדם** - לחצו על "סינון" כדי לפתוח Drawer:
   - סמנו ערוצים, ענפים, וכו'.
   - לחצו **החל סינון**.
3. **שמירת תבנית סינון** - יש 4 תבניות מוכנות מראש. ליצור משלכם - כרגע דורש פיתוח (Feature Request).
4. **נקה סינון** - בטל את כל הפילטרים.

### פעולה 8: מעבר בין תצוגות

- **יומי** - יום אחד, אירועים מסודרים לפי שעה.
- **שבועי** (ברירת מחדל) - 7 ימים.
- **חודשי** - חודש שלם, תצוגת לוח שנה.

לחיצה על הכפתורים בסרגל העליון. הלוח מתעדכן מיידית.

### פעולה 9: צפייה בחפיפות ערוץ

**מסך:** סינון מתקדם → "סטטוס מחלקות" → "ערוצים עם חפיפות".

או:

1. נסו ליצור אירוע - אם יש חפיפה תקבלו דיאלוג עם רשימת המתנגשים.
2. ניתן גם לראות בלוח - אירועים שמתנגשים יוצגו עם **גבול אדום מהבהב**.

החפיפה מוגדרת לפי: אותו ערוץ + טווח שעות חופפ. גם השוואה של ערוץ מקביל אם הוגדר.

| פעולה | Permission |
|------|-----------|
| צפייה בתכנונית | `BROADCAST_VIEW` |
| יצירה / עריכה של אירועים | `BROADCAST_MANAGE` |

| עריכת מחלקה ספציפית | תלוי במחלקה (לדוגמה: `MCR_MANAGE` לעריכת לשונית MCR) |

## טעויות נפוצות ופתרונן

- **בעיה:** "ייבוא Excel מחזיר 'אין שורות תקינות'".
  **פתרון:** ודאו ששורה 1 כותרות, ולא נתונים. שעמודות "תאריך" ו-"שעה" קיימות. שאין שורות ריקות בראש.

- **בעיה:** "אירוע נוצר אבל לא מופיע על הלוח".
  **פתרון:** ודאו שאתם בתאריך הנכון על הלוח. ייתכן שהוא ביום אחר. נסו לבחור תצוגה "חודשית" כדי לראות יותר.

- **בעיה:** "אני לא יכול ליצור אירוע - הכפתור 'צור' אפור".
  **פתרון:** חסר שדה חובה. כל שדה עם כוכבית (*) חובה: ספורט, ליגה, מארחת, אורחת, תאריך, שעות, ערוץ.

- **בעיה:** "חפיפה הזוייה - אני לא רואה שני שידורים באותו זמן".
  **פתרון:** בדקו את הערוץ המקביל - ייתכן שאירוע אחר משתמש באותו ערוץ מקביל. בדקו גם שעות בלילה (24:00 / 00:00) - שגיאת הזנה היא נפוצה.

- **בעיה:** "סטטוס מחלקה ירוק אבל אני לא רואה את הנתונים".
  **פתרון:** ייתכן שמילאתם נתוני מחלקה ישנים (legacy). פתחו את הלשונית ובדקו - אם השדות ריקים, ייתכן שהשמירה נכשלה.
