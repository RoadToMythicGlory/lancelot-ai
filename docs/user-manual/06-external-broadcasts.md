# שידורי חוץ - תכנון צוות וציוד להפקות חיצוניות

> **בעמוד "שידורי חוץ" אתם מתכננים את הצוות (צלמים, סאונדמנים, מפיקים, במאים) ואת הציוד הנדרש לכל הפקה שמתבצעת מחוץ לאולפן: משחק באצטדיון, אירוע בשטח, וכו'.**
> ניתן לשמור פריסטים (תבניות) לסוגי הפקות חוזרות, ולסמן הפקות שלא רלוונטיות אליכם.

---

## מתי משתמשים בזה?

- כדי לקבוע מי מהצוות יוצא לכל הפקת חוץ הקרובה.
- כדי להזין כמה מצלמות, מיקרופונים, רכבים, וכו' יש צורך באירוע.
- כדי לשמור פריסט להפקה חוזרת ("ליגה לאומית - משחק מרכזי").
- כדי לסמן הפקה כ"לא עבורנו" (אחרים יטפלו).

## איך נכנסים?

1. בסיידבר, לחצו על **שידורי חוץ** (אייקון גלובוס).
2. תועברו ל-`/external-broadcasts`.

הרשאה נדרשת: `BROADCAST_VIEW` (זהה לתכנונית).

## מסכים ותתי-מסכים

### 1. סרגל ניווט עליון

- **כפתורי תצוגה**: יומי / שבועי / חודשי.
- **חיצי ניווט תאריך** + **"היום"**.
- **רענן** - לטעון מחדש.

### 2. שדה חיפוש

- **חיפוש אירוע...** - הקלידו שם / קבוצה / ענף.

### 3. רשימת אירועים עם דרישות שידור-חוץ

טבלה / רשת של כרטיסי אירועים, בכל כרטיס:

- שם האירוע + ערוץ + תאריך + שעה.
- **סיכום שיבוצים**: כמה תפקידים שובצו מתוך הצרכים.
- **סיכום ציוד**: כמה קטגוריות ציוד הוגדרו.
- אייקון "לא עבורנו" אם הוסר.

לחיצה על כרטיס פותחת את **חלון פרטי האירוע** עם 2 לשוניות:

- **צוות הפקה (N)** - שיבוצי כוח אדם.
- **ציוד נדרש (M)** - רשימת ציוד מבוקש.

### 4. לשונית "צוות הפקה"

טבלה של תפקידים נדרשים:

| עמודה | תוכן |
|------|------|
| **תפקיד** | צלם / סאונדמן / מפיק / במאי / מותאם אישית |
| **כמות** | כמה אנשים בתפקיד הזה |
| **שיבוצים** | משתמשים שכבר שובצו (שמות) |
| **פעולות** | הוסף עובד / הסר |

תפקידים קבועים: **צלם** (CAM), **סאונדמן** (SOUND), **מפיק** (PROD), **במאי** (DIR). ניתן להוסיף תפקידים מותאמים אישית.

### 5. לשונית "ציוד נדרש"

טבלה של קטגוריות ציוד:

| עמודה | תוכן |
|------|------|
| **קטגוריית ציוד** | מצלמות / מיקרופונים / רכבים / שידור לוויני / וכו' |
| **כמות** | כמה יחידות |
| **הגדרות יחידה** | לכל יחידה - הגדרה ייחודית (תפקיד, ייעוד, הגדרת אודיו) |
| **פעולות** | מחיקה |

בתחתית - **סיכום דרישות ציוד** עם כפתור "הוסף" להוספת קטגוריה.

## כל פעולה צעד-אחר-צעד

### פעולה 1: שיבוץ עובד לתפקיד

**מסך:** פרטי אירוע → לשונית "צוות הפקה" → כפתור "הוסף איש צוות".

**צעדים:**

1. לחצו על האירוע שאתם רוצים לטפל בו.
2. עברו ללשונית **צוות הפקה**.
3. לחצו על **+ הוסף איש צוות**.
4. ייפתח חלון "הוסף איש צוות":
   - **בחר תפקיד** (חובה) - מהרשימה: צלם / סאונדמן / מפיק / במאי / מותאם אישית.
   - **אם בחרתם "מותאם אישית"** - יופיע שדה: **שם התפקיד** (לדוגמה: "רחפן", "גריפ", "עוזר במאי").
   - **בחר איש צוות** - רשימה נפתחת של המשתמשים מהמחלקה המתאימה. ניתן להשאיר ריק אם עוד לא יודעים מי.
5. לחצו **שמור**.
6. השורה תופיע בטבלה.

### פעולה 2: הסרת שיבוץ

**מסך:** טבלת השיבוצים → אייקון פח אדום בכל שורה.

**צעדים:**

1. לחצו על אייקון הפח.
2. תוצג בקשת אישור.
3. אשרו - השיבוץ יוסר.

### פעולה 3: הוספת קטגוריית ציוד

**מסך:** לשונית "ציוד נדרש" → כפתור "הוסף".

**צעדים:**

1. בלשונית **ציוד נדרש**, בשדה הנפתח **בחר קטגוריית ציוד** - בחרו מהרשימה: מצלמות, מיקרופונים, רכבים, וכו'.
2. הזינו **כמות** (מספר שלם).
3. לחצו **הוסף**.
4. השורה תופיע בטבלה.
5. **לכל יחידה**: הרחיבו את השורה - תופיע טבלה פנימית של היחידות:
   - **תפקיד / ייעוד** - לדוגמה: "מצלמה ראשית", "מצלמת רוחב", "במאי".
   - **הגדרת אודיו** - אם רלוונטי (לדוגמה: "ערוץ 1 - מיקרופון פרשן").
   - **הערות**.

### פעולה 4: סימון "לא עבורנו"

**מסך:** פרטי אירוע → כפתור "לא עבורנו" בראש החלון.

**צעדים:**

1. אם הפקה מסוימת לא דורשת מעורבות של הצוות שלכם (לדוגמה: הפקה חיצונית של חברה אחרת):
   - לחצו על **לא עבורנו** בראש החלון.
2. האירוע יסומן ויוצג מצומצם בעמוד.
3. ניתן לבטל את הסימון מאוחר יותר.

### פעולה 5: שמירת פריסט (תבנית הפקה)

**מסך:** פרטי אירוע → כפתור "שמור כפריסט".

**צעדים:**

1. אחרי שמילאתם את הצוות והציוד לאירוע מסוים - לחצו **שמור כפריסט**.
2. ייפתח חלון "שמירת פריסט חדש":
   - **שם הפריסט** (חובה) - לדוגמה "ליגה לאומית - משחק מרכזי".
   - **תיאור** (אופציונלי).
   - **תגיות** (multi) - הקלידו תגית ולחצו Enter (לדוגמה: "כדורגל", "ערוץ ראשי").
3. לחצו **שמור פריסט**.
4. הפריסט יהיה זמין לכל אירוע עתידי.

### פעולה 6: שימוש בפריסט קיים

**מסך:** פרטי אירוע → רשימת פריסטים נפתחת.

**צעדים:**

1. בראש פרטי האירוע, בחרו פריסט מהרשימה הנפתחת.
2. לחצו **החל פריסט** - כל השיבוצים וקטגוריות הציוד של הפריסט יוחלו (אך ללא איוש קונקרטי - רק התפקידים).
3. הוסיפו את האנשים בפועל.

### פעולה 7: עריכת / מחיקת פריסט

**מסך:** רשימת הפריסטים.

**צעדים:**

1. בתפריט הפריסטים, ליד כל פריסט יש 3 נקודות.
2. **עריכה** - פותח את חלון השמירה עם הערכים הקיימים.
3. **מחיקה** - דורש אישור: "למחוק את הפריסט?".

### פעולה 8: שמירת השינויים לאירוע

**מסך:** פרטי האירוע - כפתור "שמור" בראש החלון.

**צעדים:**

1. אחרי כל השינויים - לחצו **שמור** (כפתור עם אייקון דיסקט).
2. הסטטוס של מחלקת "שידורי חוץ" באירוע יתעדכן.
3. ב-`/broadcast-planning` תראו שהמחלקה הזו ירוקה / כתומה.

## טעויות נפוצות ופתרונן

- **בעיה:** "אני לא רואה את האירוע ברשימה".
  **פתרון:** ייתכן שהוא מסומן "לא עבורנו" - הסירו את הסינון. או שהוא בתאריך אחר - שנו את התצוגה.

- **בעיה:** "אני לא מצליח לבחור משתמש בשיבוץ".
  **פתרון:** הרשימה מוגבלת למחלקה המתאימה לתפקיד. אם המשתמש לא במחלקה - הוא לא יופיע. ניתן להשאיר ריק זמנית.

- **בעיה:** "החלת פריסט לא הוסיפה אנשים".
  **פתרון:** פריסטים שומרים רק את **התפקידים** (כמויות, ייעוד), לא את האנשים הספציפיים. צריך להוסיף את האנשים ידנית בכל אירוע.

- **בעיה:** "אין סנכרון בין הציוד כאן לבין המחסן".
  **פתרון:** "ציוד נדרש" כאן הוא ברמת קטגוריה (לדוגמה: "3 מצלמות"). המחסן הפיזי - מי בדיוק יצא, באיזה ברקודים - נעשה בעמוד `/warehouse` בלשונית "בקשות שידורי חוץ".
