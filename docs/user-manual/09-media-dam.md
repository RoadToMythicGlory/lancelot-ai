# מדיה (DAM) - ניהול נכסי דיגיטל

> **המודול "מדיה" הוא מערכת DAM (Digital Asset Management) פנימית - מאגר מרכזי של כל קבצי הוידאו, האודיו, התמונות, המסמכים והגרפיקות של הארגון.**
> כאן מעלים, מסמנים בתגיות, ממיינים לתיקיות, ומחפשים קבצים.

---

## מתי משתמשים בזה?

- כדי להעלות קובץ חדש (סרטון לוגו, תמונת רקע, מסמך הפקה).
- כדי למצוא קובץ ספציפי לפי שם / סוג / תגית.
- כדי לארגן את הקבצים בתיקיות.
- כדי לראות מי העלה איזה קובץ ומתי.

## איך נכנסים?

1. בסיידבר, תחת **ניהול**, לחצו על **מדיה (DAM)** (אייקון תמונה).
2. תועברו ל-`/media`.

הרשאה נדרשת: `MEDIA_VIEW`.

## מסכים ותתי-מסכים

### 1. כותרת ופעולות עליונות

- **כותרת**: "ניהול מדיה (DAM)".
- **תיאור**: "ניהול קבצי מדיה, תמונות, וידאו ומסמכים".
- **כפתורים בצד שמאל**:
  - **תיקיה חדשה** (אייקון תיקיה) - יוצר תיקיה.
  - **העלאת קובץ** (כחול ראשי, אייקון ענן עם חץ) - מעלה קובץ חדש.

### 2. תיקיות (Folders)

מתחת לכותרת - שורה אופקית של כרטיסי תיקיות (אם קיימות):

- אייקון תיקיה צהוב.
- שם התיקיה.
- לחיצה - תיכנס לתיקיה.

### 3. סינון וחיפוש

- **חיפוש מדיה...** - שדה טקסט.
- **סוג** - רשימה נפתחת: וידאו / אודיו / תמונה / מסמך / גרפיקה / אחר.
- **סטטוס** - מוכן / מעלה / מעבד / בארכיון.
- **N קבצים** - מציג את הסך הכל.

### 4. טבלת הקבצים

עמודות:

| עמודה | תוכן |
|------|------|
| **סוג** | אייקון לפי סוג (וידאו=סגול, אודיו=ירוק, תמונה=כחול, מסמך=כתום) |
| **שם** | כותרת + שם קובץ מקורי |
| **סוג קובץ** | תגית |
| **גודל** | KB/MB/GB |
| **סטטוס** | תגית צבעונית |
| **תגיות** | תגיות לסיווג |
| **הועלה על ידי** | שם המשתמש |
| **תאריך** | DD/MM/YYYY |
| **פעולות** | "מחק" (אדום) |

עימוד: 24 פריטים בעמוד.

## כל פעולה צעד-אחר-צעד

### פעולה 1: העלאת קובץ

**מסך:** כפתור "העלאת קובץ" בפינה השמאלית-עליונה.

**צעדים:**

1. לחצו **העלאת קובץ**.
2. ייפתח דיאלוג בחירת קובץ של המערכת.
3. בחרו קובץ (תמיכה: וידאו, אודיו, תמונות, מסמכים).
4. הקובץ ייעלה - תופיע התקדמות.
5. אחרי העלאה - יתבצע עיבוד (תמונות ממוזערות לתמונות וידאו, וכו'). הסטטוס יעבור מ-"מעלה" → "מעבד" → "מוכן".
6. הקובץ יופיע בטבלה.

**הרשאה:** `MEDIA_MANAGE`.

### פעולה 2: יצירת תיקיה

**מסך:** כפתור "תיקיה חדשה" בפינה השמאלית-עליונה.

**צעדים:**

1. לחצו **תיקיה חדשה**.
2. ייפתח חלון "יצירת תיקיה חדשה":
   - **שם תיקיה** (חובה) - באנגלית, לדוגמה: "Logos".
   - **שם בעברית** (אופציונלי) - "לוגואים".
3. לחצו **צור תיקיה**.
4. התיקיה תופיע ברשימת התיקיות.

### פעולה 3: חיפוש קובץ

**מסך:** סרגל הסינון.

**צעדים:**

1. הקלידו בשדה **חיפוש מדיה...**.
2. הטבלה תסתנן בזמן אמת.
3. ניתן גם לסנן לפי **סוג** ו-**סטטוס** במקביל.

### פעולה 4: מחיקת קובץ

**מסך:** כפתור "מחק" אדום בעמודת פעולות.

**צעדים:**

1. בשורת הקובץ, לחצו **מחק**.
2. ייפתח דיאלוג: "מחיקת קובץ - האם אתה בטוח?".
3. לחצו **מחק** (אדום) או **ביטול**.
4. הקובץ ייעלם מהרשימה.

**זהירות:** ייתכן שהקובץ בשימוש באירוע / פוסט - בדקו לפני מחיקה.

### פעולה 5: צפייה / הורדה של קובץ

**מסך:** לחיצה על שם הקובץ בטבלה.

**צעדים:**

1. לחצו על שם הקובץ.
2. ייפתח חלון תצוגה מקדימה (לתמונות / וידאו / אודיו).
3. כפתורים:
   - **הורד** - הורדה למחשב.
   - **שתף** - יוצר קישור שיתוף.
   - **ערוך תגיות** - להוסיף/להסיר תגיות.

## הרשאות נדרשות

| פעולה | Permission |
|------|-----------|
| צפייה | `MEDIA_VIEW` |
| העלאה, מחיקה, יצירת תיקיות | `MEDIA_MANAGE` |

## טעויות נפוצות ופתרונן

- **בעיה:** "ההעלאה נכשלת".
  **פתרון:** ייתכן שהקובץ גדול מדי (תלוי בהגדרות הארגון). או שהסיומת לא נתמכת. או שהארגון הגיע למכסת אחסון (`14-billing.md`).

- **בעיה:** "אני לא רואה קובץ שהעליתי".
  **פתרון:** רעננו את הדף. ייתכן שהוא עדיין בעיבוד - חכו דקה.

- **בעיה:** "הסטטוס תקוע על 'מעבד' זמן רב".
  **פתרון:** קבצים גדולים יכולים לקחת זמן. אם זה יותר מ-15 דקות - פנו ל-IT.
