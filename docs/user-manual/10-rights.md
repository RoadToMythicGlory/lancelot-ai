# זכויות שידור - חוזים, תפוגות וניהול

> **המודול "זכויות שידור" מנהל את החוזים והרישיונות לתוכן ששודר/יוצג בערוצים: זכויות לליגות ספורט, סדרות, סרטים, וכו'.**
> כאן רואים מתי כל זכות פגה, מי בעל הזכויות, מה העלות, ומקבלים התראה לפני שזכות פגה.

---

## מתי משתמשים בזה?

- כדי להוסיף חוזה חדש שנחתם.
- כדי לדעת אילו זכויות הולכות לפוג בקרוב.
- כדי לחפש זכויות לפי ליגה / ספורט / בעל זכויות.
- לחישוב סך העלויות של זכויות פעילות.

## איך נכנסים?

1. בסיידבר, תחת **ניהול**, לחצו על **זכויות שידור** (אייקון תעודה).
2. תועברו ל-`/rights`.

הרשאה נדרשת: `RIGHTS_VIEW`.

## מסכים ותתי-מסכים

### 1. כותרת ופעולות עליונות

- **כותרת**: "ניהול זכויות שידור".
- **תיאור**: "ניהול חוזים, זכויות שידור, שטחים ותפוגות".
- **כפתור "+ זכות חדשה"** (כחול ראשי).

### 2. התראת פקיעה

אם יש זכויות שיפוגו ב-30 הימים הקרובים - מופיעה התראה כתומה:

**"X זכויות פגות תוקף ב-30 הימים הקרובים"** + כפתור "הצג".

### 3. כרטיסי סטטיסטיקה (4)

- **סך הכל** - מספר הזכויות במאגר.
- **פעילות** (ירוק) - סטטוס "active".
- **פגות בקרוב** (כתום) - סטטוס "expiring_soon".
- **עלות כוללת** ($) - סכום של כל הזכויות.

### 4. סינון וחיפוש

- **חיפוש...** (טקסט).
- **סוג תוכן**: ספורט / בידור / חדשות / דוקומנטרי / סרט / סדרה / אחר.
- **סטטוס**: טיוטה / פעיל / פג בקרוב / פג תוקף / בוטל.

### 5. טבלת הזכויות

עמודות:

| עמודה | תוכן |
|------|------|
| **כותרת** | שם הזכות + ספורט / ליגה (משנית) |
| **סוג** | תגית (ספורט / בידור / וכו') |
| **בעל הזכויות** | שם הצד השני בחוזה |
| **תחילה** | DD/MM/YYYY |
| **סיום** | DD/MM/YYYY - **בצבע כתום אם פג בתוך 30 יום** |
| **בלעדיות** | בלעדי (זהב) / לא בלעדי / שיתופי |
| **עלות** | סכום + מטבע |
| **סטטוס** | תגית צבעונית |
| **פעולות** | "מחק" (אדום) |

עימוד: 20 בעמוד.

---

## כל פעולה צעד-אחר-צעד

### פעולה 1: הוספת זכות שידור חדשה

**מסך:** כפתור "+ זכות חדשה" בפינה השמאלית-עליונה.

**צעדים:**

1. לחצו **+ זכות חדשה**.
2. ייפתח חלון "הוספת זכות שידור" ברוחב 700px.
3. מלאו (שדות חובה מסומנים):

#### שדות בסיסיים

- **כותרת** (חובה) - לדוגמה: "ליגת העל בכדורגל - עונת 2025/26".
- **סוג תוכן** (חובה) - בחרו מהרשימה.
- **בעל הזכויות** (חובה) - לדוגמה: "התאחדות הכדורגל".
- **מספר חוזה** (אופציונלי) - לאישור פנימי.

#### פרטי ספורט (לזכויות ספורט)

- **ענף ספורט** - "כדורגל", "כדורסל"...
- **ליגה** - "ליגת העל"...

#### תאריכים ועלות

- **תאריך התחלה** (חובה).
- **תאריך סיום** (חובה).
- **בלעדיות** - בלעדי / לא בלעדי / שיתופי.
- **עלות** - מספר.

#### הערות

- **הערות** - טקסט חופשי, לדוגמה: "תנאים מיוחדים", "חידוש אוטומטי".

4. לחצו **צור זכות שידור**.
5. תוצג בטבלה.

**הרשאה:** `RIGHTS_MANAGE`.

### פעולה 2: מחיקת זכות

**מסך:** כפתור "מחק" (אדום) בעמודת פעולות.

**צעדים:**

1. לחצו **מחק**.
2. ייפתח דיאלוג: "מחיקת זכות שידור - האם אתה בטוח?".
3. אשרו - הזכות תוסר.

**זהירות:** מחיקה היא קבועה. עדיף לעדכן סטטוס ל-"בוטל".

### פעולה 3: סינון וחיפוש

עיינו ב-"מסכים ותתי-מסכים" → סינון.

### פעולה 4: צפייה בזכות שפגה

זכויות שפגו (`expired`) או שיפגו בקרוב (`expiring_soon`) - מסומנות בצבעים. סננו לפי סטטוס לראות רק אותן.

### פעולה 5: עריכת זכות קיימת

כרגע אין כפתור "ערוך" ישיר. ניתן ליצור זכות חדשה (עדכון) או לערוך דרך GraphQL ישירות (פיתוח עתידי).

## הרשאות נדרשות

| פעולה | Permission |
|------|-----------|
| צפייה | `RIGHTS_VIEW` |
| הוספה / מחיקה | `RIGHTS_MANAGE` |

---

## טעויות נפוצות ופתרונן

- **בעיה:** "הזכות מציגה 'expiring_soon' אבל אני יודע שחתמנו חידוש".
  **פתרון:** עדכון חידוש דורש יצירת זכות חדשה. הזכות הישנה תיוותר במאגר לתיעוד.

- **בעיה:** "העלות הכוללת לא תואמת את החישוב שלי".
  **פתרון:** המערכת סוכמת רק זכויות עם שדה "עלות" ממולא. ייתכן שכמה זכויות בלי עלות.
