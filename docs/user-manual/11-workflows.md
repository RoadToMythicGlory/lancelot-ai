# תהליכים (Workflows) - אישורים, SLA ואוטומציה

> **המודול "תהליכים" הוא מנוע אישורים אוטומטי. כשמתבצעת פעולה שדורשת אישור (לדוגמה: בקשת חופשה, אישור הוצאה גדולה), המערכת פותחת "תהליך" שעובר דרך שלבי האישור עד שהוא מאושר או נדחה.**
> כאן רואים את התהליכים שיזמתם, התהליכים שאתם צריכים לאשר, ואת התבניות הכלליות של התהליכים.

---

## מתי משתמשים בזה?

- כדי לראות אילו אישורים ממתינים לכם.
- כדי לאשר / לדחות בקשות.
- כדי לעקוב אחר תהליכים שהתחלתם (לדוגמה: בקשת חופשה שאתם המגיש).
- כדי לבדוק האם תהליך הופר בגלל חריגת SLA.
- (מנהל) להגדיר תבניות תהליכים חדשות.

## איך נכנסים?

1. בסיידבר, תחת **ניהול**, לחצו על **תהליכים** (אייקון חצים מעגליים).
2. תועברו ל-`/workflows`.

הרשאה נדרשת: `WORKFLOWS_VIEW`.

## מסכים ותתי-מסכים

### 1. כותרת

- **כותרת**: "מנוע תהליכים".
- **תיאור**: "ניהול תהליכי אישור, אוטומציות ו-SLA".

### 2. כרטיס "אישורים ממתינים" (כתום)

אם יש לכם אישורים ממתינים - יופיע כרטיס כתום בולט בראש הדף:

**"X אישורים ממתינים"** + רשימה של כל אחד עם:
- **שם התבנית** (לדוגמה: "אישור חופשה").
- **שם המשאב** (לדוגמה: "חופשה של דני - 5/3-10/3") + **שם היוזם**.
- **כפתורים**:
  - **אשר** (כחול) - אישור מהיר.
  - **דחה** (אדום) - דחיה מהירה.

### 3. לשוניות (Tabs)

#### לשונית "תהליכים (N)"

טבלת כל התהליכים:

| עמודה | תוכן |
|------|------|
| **תהליך** | שם התבנית + שם המשאב |
| **סטטוס** | Badge: בתהליך / הושלם / בוטל / נכשל / ממתין |
| **שלב נוכחי** | תגית עם שם השלב |
| **SLA** | "X שעות נותרו" או תגית אדומה "חריגת SLA" |
| **יוזם** | שם המשתמש שיזם |
| **תאריך** | DD/MM/YYYY |
| **פעולות** | "פרטים" - פותח חלון פרטי תהליך |

עימוד: 15 בעמוד.

#### לשונית "תבניות (M)"

טבלת תבניות התהליכים:

| עמודה | תוכן |
|------|------|
| **שם** | שם התבנית |
| **טריגר** | מה מפעיל את התהליך (אוטומטי / ידני) |
| **סוג משאב** | על מה התהליך פועל (חופשה, הוצאה, וכו') |
| **שלבים** | מספר שלבים |
| **פעיל** | תגית ירוקה/אפורה |

### 4. חלון פרטי תהליך

לחיצה על "פרטים" פותחת חלון מודאלי:

- **תבנית** - השם.
- **משאב** - המשאב הקשור (אם קיים).
- **סטטוס** + Badge.
- **שלבים** - תצוגת `Steps` אנכית:
  - כל שלב: שם, מי מאשר, מתי הושלם.
  - סטטוס שלב: ✓ הושלם (ירוק) / ✗ נדחה (אדום) / ⊙ ממתין / ⊘ ממתין לכם.

## כל פעולה צעד-אחר-צעד

### פעולה 1: אישור / דחיית בקשה

**מסך:** כרטיס "אישורים ממתינים" בראש הדף (אם יש).

**צעדים:**

1. בכרטיס הכתום, מצאו את הבקשה.
2. קראו את תיאור המשאב כדי להבין על מה אתם מאשרים.
3. לחצו:
   - **אשר** (כחול) - אם בסדר.
   - **דחה** (אדום) - אם לא.
4. ייתכן שייפתח דיאלוג קצר לבקש הערה / הסבר.
5. אחרי האישור - התהליך עובר לשלב הבא (או סוגר אם זה היה השלב האחרון).
6. היוזם יקבל התראה.

### פעולה 2: צפייה בפרטי תהליך

**מסך:** לשונית "תהליכים" → כפתור "פרטים".

**צעדים:**

1. לחצו **פרטים** בשורה.
2. ייפתח חלון פרטים.
3. סקרו את **השלבים** - תצוגת Steps אנכית:
   - מי בכל שלב.
   - מתי בוצע.
   - מצב כל שלב.
4. סגרו ב-X.

### פעולה 3: בדיקת תהליכים שיזמתם

עברו ללשונית **תהליכים** וחפשו לפי השם שלכם בעמודת "יוזם".

(או דרך Inbox / התראות - כשמשתנה סטטוס תקבלו עדכון.)

### פעולה 4: יצירת תבנית תהליך חדשה

זוהי פעולה מתקדמת. כרגע אין כפתור ישיר ב-UI - דורש הרשאה `WORKFLOWS_MANAGE` ו/או הקמה דרך הצד השרת.

**עקרון התבנית:**

- **שם** - לדוגמה "אישור הוצאה > 5000 ₪".
- **טריגר** - מתי התבנית מופעלת (אוטומטית / ידנית / על אירוע).
- **סוג משאב** - על מה היא פועלת.
- **שלבים** - רשימה מסודרת:
  - כל שלב: שם, מי מאשר (משתמש / תפקיד), זמן SLA.
- **פעיל** - לאחר יצירה, האם להפעיל.

---

## הרשאות נדרשות

| פעולה | Permission |
|------|-----------|
| צפייה | `WORKFLOWS_VIEW` |
| יצירה / עריכה של תבניות | `WORKFLOWS_MANAGE` |
| אישור / דחיית בקשה ספציפית | מי שמוגדר כמאשר בשלב |

---

## טעויות נפוצות ופתרונן

- **בעיה:** "אני לא רואה את האישור שמחכה לי".
  **פתרון:** ייתכן שכבר אישרתם או שזה הוקצה למישהו אחר. בדקו ב-Inbox (אייקון מעטפה).

- **בעיה:** "תהליך תקוע על שלב X זמן רב".
  **פתרון:** בדקו אם המאשר זמין. אם הוא לא - מנהל יכול להעביר את האחריות למישהו אחר (דורש `WORKFLOWS_MANAGE`).

- **בעיה:** "ראיתי 'חריגת SLA'".
  **פתרון:** התהליך לא הושלם בזמן שהוגדר ב-SLA של התבנית. זה לא חוסם - רק מתעד. שיקלו להאיץ.
