# הגדרות - ארגון, תכונות, אבטחה והתראות

> **בעמוד "הגדרות" מנהלים את ההגדרות הארגוניות הכלליות: פרטי הארגון (שם, כתובת), הפעלת/השבתת תכונות, מדיניות אבטחה והעדפות התראה.**
> זהו עמוד למנהלים בעיקר - שינויים כאן משפיעים על כל המשתמשים בארגון.

---

## מתי משתמשים בזה?

- כשמקימים ארגון חדש - להזין פרטים בסיסיים.
- כדי להפעיל / להשבית מודולים (לדוגמה: אם לא משתמשים ב-MCR, לכבות אותו).
- כדי לחזק אבטחה - לדרוש MFA, להאריך אורך סיסמה.
- כדי להפעיל SSO.
- כדי לקבוע אילו התראות מקבל הארגון.

## איך נכנסים?

1. בסיידבר, תחת **מערכת**, לחצו על **הגדרות** (אייקון גלגל שיניים).
2. תועברו ל-`/settings`.

הרשאה לצפייה: `SETTINGS_VIEW`. הרשאה לעריכה: `SETTINGS_MANAGE`.

## מסכים ותתי-מסכים

הדף מחולק ל-4 לשוניות (Tabs בצד ימין):

### לשונית 1: ארגון

#### פרטי ארגון

טופס עם השדות:
- **שם ארגון (אנגלית)** - לדוגמה: "Acme Broadcasting".
- **שם ארגון (עברית)** - לדוגמה: "Acme שידור בע"מ".
- **אימייל ליצירת קשר**.
- **טלפון**.
- **כתובת**.
- **מדינה**.

כפתור **שמור שינויים**.

#### הגדרות כלליות

טופס נוסף בתחתית:
- **אזור זמן** - Asia/Jerusalem (ברירת מחדל) / UTC / America/New_York / Europe/London.
- **שפה** - עברית / English.
- **פורמט תאריך** - DD/MM/YYYY / MM/DD/YYYY / YYYY-MM-DD.
- **צבע מותג** - בוחר צבע (מציג כפתורים בכל המערכת).

כפתור **שמור הגדרות**.

### לשונית 2: תכונות (Feature Flags)

הפעלה/השבתה של מודולים שלמים. **שינוי כאן משפיע על מה שמופיע בסיידבר לכל המשתמשים בארגון**.

| מתג | משמעות |
|-----|---------|
| **תכנון שידורים** | תכנונית `/broadcast-planning` |
| **MCR** | חדר בקרה ראשי |
| **משמרות** | ניהול משמרות |
| **מחסן** | ניהול ציוד |
| **צ'אט** | מערכת הודעות פנימית |
| **סוכן AI** | עוזר AI חכם |
| **Vizrt/גרפיקה** | אינטגרציית גרפיקה |
| **ניטור חי** | ניטור סיגנלים בזמן אמת |

כל מתג: שם + תיאור + Switch. לחצו על המתג להפעלה/השבתה.

כפתור **שמור תכונות** בתחתית.

### לשונית 3: אבטחה

#### MFA (אימות דו-שלבי)

- **חובה לכל המשתמשים** - מתג.
- אם הופעל - כל משתמש יידרש להגדיר אפליקציית Authenticator (Google Auth / Authy) בכניסה הבאה שלו.

#### SSO (Single Sign-On)

- **הפעלת SSO** - מתג.
- אם הופעל - תיאלצו להזין הגדרות SAML/OAuth של ספק הזהות הארגוני (Azure AD / Google Workspace / Okta).

#### מדיניות סיסמה

- **אורך סיסמה מינימלי** - מספר בין 6-32. ברירת מחדל 8.
- **זמן פקיעת הפעלה (דקות)** - בין 15 ל-1440 (24 שעות). ברירת מחדל 1440.

כפתור **שמור הגדרות אבטחה**.

### לשונית 4: התראות

רשימת סוגי התראות אפשריים, לכל אחד תיוגי ערוצים (אפליקציה / אימייל / Push):

- שידור חדש נוצר
- שידור עודכן
- שידור בוטל
- שובצת למשמרת
- בקשת החלפת משמרת
- תזכורת משמרת
- נדרש אישור
- ציוד שובץ
- התראת מערכת

הגדרה זו היא **ברמת המשתמש** - כל משתמש יכול לבחור איזה התראות לקבל ובאיזה ערוצים.

## כל פעולה צעד-אחר-צעד

### פעולה 1: עדכון פרטי הארגון

**מסך:** לשונית "ארגון" → טופס "פרטי ארגון".

**צעדים:**

1. עברו ללשונית **ארגון**.
2. ערכו את הפרטים בטופס.
3. לחצו **שמור שינויים**.
4. תוצג הודעה ירוקה "הגדרות הארגון עודכנו בהצלחה".

### פעולה 2: שינוי אזור זמן / פורמט תאריך

**מסך:** לשונית "ארגון" → טופס "הגדרות כלליות".

**צעדים:**

1. בחרו **אזור זמן** מהרשימה.
2. בחרו **פורמט תאריך**.
3. לחצו **שמור הגדרות**.

**חשוב:** שינוי אזור זמן משפיע על כל התאריכים והשעות במערכת. אם הארגון פועל מישראל - השאירו `Asia/Jerusalem`.

### פעולה 3: הפעלת / השבתת מודול

**מסך:** לשונית "תכונות".

**צעדים:**

1. עברו ללשונית **תכונות**.
2. לחצו על המתג של המודול שאתם רוצים להפעיל/לכבות.
3. לחצו **שמור תכונות**.
4. **משתמשים שיתחברו אחרי השינוי** - יראו / לא יראו את המודול בסיידבר.

**זהירות:** השבתת מודול לא מוחקת את הנתונים שלו - רק מסתירה את הכניסה. ניתן להחזיר בכל עת.

### פעולה 4: דרישת MFA לכל הארגון

**מסך:** לשונית "אבטחה" → MFA.

**צעדים:**

1. הפעילו את המתג **חובה לכל המשתמשים**.
2. לחצו **שמור הגדרות אבטחה**.
3. בכניסה הבאה, כל משתמש שעוד לא הגדיר MFA יידרש לעשות זאת:
   - הורדת אפליקציה (Google Authenticator / Authy).
   - סריקת QR code.
   - הזנת קוד 6-ספרתי לאישור.

### פעולה 5: שינוי אורך סיסמה מינימלי

**מסך:** לשונית "אבטחה".

**צעדים:**

1. בשדה **אורך סיסמה מינימלי**, שנו את הערך (6-32).
2. שמרו.
3. שינוי זה חל רק על **סיסמאות חדשות**. סיסמאות קיימות נשארות.

### פעולה 6: הארכת/קיצור זמן פקיעת הפעלה

**מסך:** לשונית "אבטחה".

**צעדים:**

1. בשדה **זמן פקיעת הפעלה**, שנו לדקות הרצויות (15-1440).
2. שמרו.
3. הפעלות קיימות לא משתנות - רק הפעלות חדשות.

## הרשאות נדרשות

| פעולה | Permission |
|------|-----------|
| צפייה בהגדרות | `SETTINGS_VIEW` |
| עריכת הגדרות | `SETTINGS_MANAGE` |

`SYSTEM_ADMIN` ו-`IT_ADMIN` מקבלים אוטומטית את שתיהן.

## טעויות נפוצות ופתרונן

- **בעיה:** "אני רואה הגדרות אבל הכפתורים 'שמור' מושבתים".
  **פתרון:** יש לכם רק `SETTINGS_VIEW` ולא `SETTINGS_MANAGE`. דברו עם IT_ADMIN.

- **בעיה:** "הפעלתי MFA אבל אני נכנס בלי קוד".
  **פתרון:** ייתכן שכבר הגדרתם MFA פעם. אם לא - המערכת מבקשת בכניסה הבאה ולא בפעם הזו.

- **בעיה:** "שיניתי אזור זמן ועכשיו השעות בלוח לא הגיוניות".
  **פתרון:** התאריכים נשמרים ב-UTC. שינוי אזור זמן משנה רק את התצוגה. ודאו שהמתכננים יודעים את אזור הזמן החדש.

- **בעיה:** "כיביתי מודול אבל המשתמשים עדיין רואים אותו".
  **פתרון:** משתמשים שהיו מחוברים לפני השינוי יראו עד הרענון הבא. הם יבטלו אחרי F5 או בכניסה הבאה.
