# חיוב ומנוי - תוכניות, שדרוג וחשבוניות

> **בעמוד "חיוב" רואים את המנוי הנוכחי של הארגון, השימוש הקיים מול מכסות התוכנית, היסטוריית חשבוניות, ויש אפשרות לשדרג / לבטל.**
> זהו עמוד למנהלי הארגון בלבד - שינויים כאן משפיעים על כל הארגון ועל החיוב הכספי.

---

## מתי משתמשים בזה?

- כדי לראות איזו תוכנית מנוי יש לארגון.
- כדי לבדוק כמה משתמשים / קבצים / שעות שידור צרכנו החודש.
- כדי לשדרג לתוכנית גדולה יותר אם הגענו לתקרה.
- כדי להוריד חשבוניות לארכוב חשבונאי.
- כדי לבטל מנוי.

## איך נכנסים?

1. בסיידבר, תחת **מערכת**, לחצו על **חיוב** (אייקון כרטיס אשראי).
2. תועברו ל-`/billing`.

הרשאה נדרשת: `BILLING_VIEW`.

## מסכים ותתי-מסכים

### 1. כותרת

- **כותרת**: "חיוב ומנוי".
- **תיאור**: "ניהול מנוי, חשבוניות וחיוב".

### 2. אזהרת תוקף

אם המנוי בתקופת ניסיון (`trial`) - מופיע באנר כתום: **"תקופת ניסיון - X ימים נותרו"**.
אם המנוי מבוטל - באנר אדום.

### 3. כרטיס "המנוי שלך"

מציג:
- **שם התוכנית** (לדוגמה: "Standard").
- **מחיר חודשי** (USD).
- **סטטוס**: פעיל / ניסיון / מבוטל / משולם.
- **תאריך חידוש הבא**.
- **כפתורים**: "שדרג תוכנית" / "בטל מנוי" / "ניהול אמצעי תשלום".

### 4. כרטיסי שימוש

4 כרטיסים שמציגים שימוש מול מכסה:

| מדד | פורמט | אזהרה |
|------|--------|--------|
| **משתמשים** | "X / Y" + Progress bar | אדום אם > 90% |
| **אחסון** | "X GB / Y GB" | אדום אם > 90% |
| **שעות שידור** | "X / Y" החודש | אדום אם > 90% |
| **קריאות API** | "X / Y" החודש | כתום אם > 80% |

### 5. תוכניות זמינות

רשת של כרטיסי תוכניות:

- **Free** - 5 משתמשים, 5GB, 0 שעות שידור, $0/חודש.
- **Starter** - 20 משתמשים, 50GB, 100 שעות, $99/חודש.
- **Standard** - 100 משתמשים, 500GB, 500 שעות, $499/חודש (פופולרי).
- **Premium** - 500 משתמשים, 5TB, ללא הגבלה, $1999/חודש.
- **Enterprise** - מותאם אישית, צרו קשר.

לכל כרטיס - כפתור "**שדרג לתוכנית זו**" או "**התוכנית הנוכחית**" (אם זו התוכנית הפעילה).

### 6. היסטוריית חשבוניות

טבלה:

| עמודה | תוכן |
|------|------|
| **מספר חשבונית** | INV-2026-001 |
| **תאריך** | DD/MM/YYYY |
| **סכום** | $X |
| **סטטוס** | שולם (ירוק) / ממתין (כתום) / נכשל (אדום) |
| **פעולות** | "הורד PDF" |

## כל פעולה צעד-אחר-צעד

### פעולה 1: צפייה במנוי הנוכחי

עברו ל-`/billing` - הכרטיס "המנוי שלך" בראש הדף מציג הכל.

### פעולה 2: שדרוג לתוכנית חדשה

**מסך:** רשת התוכניות.

**צעדים:**

1. מצאו את התוכנית הרצויה.
2. לחצו על **שדרג לתוכנית זו**.
3. ייפתח חלון אישור עם:
   - שם התוכנית החדשה.
   - הפרשי מחיר.
   - תאריך התחלת החיוב החדש (פרורטה לפי תאריך השדרוג).
4. הזינו אמצעי תשלום (אם עוד אין).
5. לחצו **אשר שדרוג**.
6. המנוי יעבור לחדש מיד; המכסות יתעדכנו.

**הרשאה:** `BILLING_MANAGE`.

### פעולה 3: ביטול מנוי

**מסך:** כפתור "בטל מנוי" בכרטיס המנוי.

**צעדים:**

1. לחצו **בטל מנוי**.
2. ייפתח חלון:
   - **סיבה לביטול** (אופציונלי) - לסייע לנו לשפר.
   - **אזהרה**: "המנוי שלך יבוטל בתאריך X. עד אז, יש לך גישה מלאה. אחר כך, הנתונים יישמרו 30 יום ואז יימחקו."
3. אשרו.
4. המנוי יסומן `cancelled` - יישאר פעיל עד סוף התקופה ששולמה.

### פעולה 4: הורדת חשבונית

**מסך:** טבלת ההיסטוריה → כפתור "הורד PDF".

**צעדים:**

1. בטבלת ההיסטוריה, מצאו את החשבונית.
2. לחצו **הורד PDF**.
3. הקובץ יורד למחשב.

### פעולה 5: ניהול אמצעי תשלום

**מסך:** כפתור "ניהול אמצעי תשלום" בכרטיס המנוי.

**צעדים:**

1. לחצו על הכפתור.
2. ייפתח חלון לעדכון:
   - מספר כרטיס אשראי.
   - תאריך תפוגה.
   - CVV.
   - כתובת חיוב.
3. שמרו.
4. החיוב הבא ילך לכרטיס החדש.

## הרשאות נדרשות

| פעולה | Permission |
|------|-----------|
| צפייה במנוי, שימוש, חשבוניות | `BILLING_VIEW` |
| שדרוג / ביטול / שינוי אמצעי תשלום | `BILLING_MANAGE` |

---

## טעויות נפוצות ופתרונן

- **בעיה:** "אני רואה 'משתמשים X/Y' אבל ה-X גדול מ-Y".
  **פתרון:** הארגון חרג ממכסה. שדרגו תוכנית או השביתו משתמשים לא פעילים.

- **בעיה:** "חשבונית מסומנת 'נכשל'".
  **פתרון:** הכרטיס נדחה. עדכנו אמצעי תשלום ונסו שוב (כפתור "נסה שוב" אם קיים).

- **בעיה:** "אני בתקופת ניסיון אבל לא רואה כפתור 'שדרג לתוכנית מלאה'".
  **פתרון:** ייתכן שדרושה הרשאת `BILLING_MANAGE`. בקשו מ-SYSTEM_ADMIN.
