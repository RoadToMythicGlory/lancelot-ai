# יומן ביקורת - מעקב אחר כל הפעולות במערכת

> **יומן הביקורת (Audit Log) הוא תיעוד מלא של כל הפעולות שמתבצעות במערכת: מי יצר, ערך, מחק, התחבר, התנתק, או שינה הגדרה.**
> זה כלי קריטי לתחקור, ציות (compliance), ולגילוי שימוש לא ראוי.

---

## מתי משתמשים בזה?

- כדי לבדוק "מי שינה את X?" - לדוגמה: מי מחק אירוע שידור / מי שינה הרשאות.
- כדי לעקוב אחר ניסיונות התחברות נכשלים.
- לתחקור אירוע אבטחה - מה קרה ומתי.
- לציות (compliance) - לעיתים נדרש לשמור היסטוריה.

## איך נכנסים?

1. בסיידבר, תחת **מערכת**, לחצו על **יומן ביקורת** (אייקון מגן).
2. תועברו ל-`/audit-log`.

הרשאה נדרשת: `AUDIT_VIEW`. שמורה ל-SYSTEM_ADMIN, IT_ADMIN, או IT_USER עם הרשאה ספציפית.

## מסכים ותתי-מסכים

### 1. כותרת

- **כותרת**: "יומן ביקורת".
- **תיאור**: "מעקב אחר כל הפעולות שבוצעו במערכת".

### 2. פילטרים

שורת פילטרים בראש הטבלה:

- **חיפוש...** - טקסט חופשי (שם משתמש, שם משאב).
- **פעולה** - יצר / ערך / מחק / התחבר / התנתק / יבא / ייצא וכו'.
- **משאב** - משתמש / שידור / משמרת / ציוד / וכו'.
- **חומרה**: Info (אפור) / Warning (כתום) / Critical (אדום).

### 3. טבלת הרשומות

עמודות:

| עמודה | תוכן |
|------|------|
| **זמן** | DD/MM/YYYY HH:MM:SS |
| **משתמש** | שם + מייל של מי שביצע |
| **פעולה** | תגית עברית של סוג הפעולה |
| **משאב** | על מה הפעולה (משתמש Joe / שידור Y / וכו') + שם המשאב |
| **חומרה** | תגית צבעונית |
| **שינויים** | "N שינויים" - לחיצה פותחת חלון פרטים |

עימוד עם הצגת "סה"כ N רשומות".

### 4. חלון פרטי שינויים (Drawer)

לחיצה על "N שינויים" פותחת Drawer מצד שמאל:

- **פעולה** (לדוגמה "עריכה").
- **משאב** + שם.
- **שינויים** - לכל שדה ששונה:
  - שם השדה.
  - **לפני** (אדום) - JSON של הערך הישן.
  - **אחרי** (ירוק) - JSON של הערך החדש.

## כל פעולה צעד-אחר-צעד

### פעולה 1: חיפוש פעולות של משתמש ספציפי

**צעדים:**

1. בשדה החיפוש בראש הדף, הקלידו שם / מייל של המשתמש.
2. הטבלה תסתנן בזמן אמת לפעולות של המשתמש בלבד.

### פעולה 2: סינון פעולות מחיקה

**צעדים:**

1. בפילטר **פעולה**, בחרו "מחיקה" (DELETE).
2. הטבלה תציג רק פעולות מחיקה.

### פעולה 3: צפייה בשינויי שדה

**צעדים:**

1. מצאו שורה עם "N שינויים" בעמודת "שינויים".
2. לחצו על הקישור.
3. ייפתח Drawer מצד שמאל:
   - תראו לכל שדה ששונה: ערך לפני (אדום) וערך אחרי (ירוק).
4. סגרו ב-X.

### פעולה 4: סינון לפי חומרה (Critical)

**צעדים:**

1. בפילטר **חומרה**, בחרו "Critical".
2. הטבלה תציג רק אירועים חמורים: מחיקות מסיביות, ניסיונות פריצה, וכו'.

### פעולה 5: סינון לפי משאב

**צעדים:**

1. בפילטר **משאב**, בחרו "משתמש" / "שידור" / "ציוד" / וכו'.
2. הטבלה תסתנן.

### פעולה 6: ייצוא ל-CSV / Excel

כרגע אין כפתור ייצוא ישיר ב-UI. ייצוא דורש GraphQL ישירות (פיתוח עתידי).

## הרשאות נדרשות

| פעולה | Permission |
|------|-----------|
| צפייה ביומן | `AUDIT_VIEW` |

כל הפעולות מתועדות אוטומטית - אין צורך לעשות פעולה ייעודית.

## טעויות נפוצות ופתרונן

- **בעיה:** "אני לא רואה את הפעולה שעשיתי לפני 10 שניות".
  **פתרון:** רעננו את הדף. תיעוד נכתב סינכרונית ברוב הפעולות, אבל לפעמים יש דיליי קצר.

- **בעיה:** "השינויים בעמודת 'שינויים' לא מובנים".
  **פתרון:** הערכים מוצגים כ-JSON גולמי. אם זה שדה מורכב (מערך, אובייקט) - ייתכן שיהיה קשה לקרוא. בעתיד יהיה תרגום ידידותי יותר.

- **בעיה:** "פעולה חשובה לא מתועדת".
  **פתרון:** ייתכן שיש באג בקוד שלא מתעד את הפעולה. דווחו ל-IT. הם יבדקו את `audit.middleware.ts`.
