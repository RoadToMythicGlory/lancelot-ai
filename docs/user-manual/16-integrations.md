# אינטגרציות - API Keys, Webhooks ומערכות חיצוניות

> **בעמוד "אינטגרציות" מנהלים את כל החיבורים החיצוניים של המערכת: מפתחות API לפיתוחים מותאמים, Webhooks להתראות אוטומטיות למערכות אחרות, ואינטגרציות מובנות (כמו Vizrt לגרפיקה).**

---

## מתי משתמשים בזה?

- כדי לתת לכלי חיצוני (אפליקציה / סקריפט) גישה ל-API של Lancelot.
- כדי שמערכת אחרת תקבל התראה כשמשהו קורה בלנסלוט (Webhooks).
- כדי לחבר את Vizrt לשליחת גרפיקה.
- כדי לבדוק שמירת חיבורים פעילים.

## איך נכנסים?

1. בסיידבר, תחת **מערכת**, לחצו על **אינטגרציות** (אם זמין; אחרת ב-`/integrations` ישירות).
2. תועברו ל-`/integrations`.

הרשאה נדרשת: `INTEGRATIONS_VIEW`.

## מסכים ותתי-מסכים

### לשונית 1: API Keys

מציג רשימת מפתחות API פעילים. כל מפתח:

- **שם** - תיאור (לדוגמה: "Script של דוחות שבועיים").
- **קידומת המפתח** - 8 התווים הראשונים (לעולם לא מציגים את המפתח המלא אחרי יצירה).
- **הרשאות** - אילו פעולות אפשר לעשות עם המפתח (READ / WRITE / ADMIN).
- **תאריך יצירה**.
- **שימוש אחרון**.
- **פעולות**: "בטל" (אדום).

**+ צור מפתח חדש** - כפתור בראש.

### לשונית 2: Webhooks

מציג רשימת Webhooks:

- **URL** - הכתובת לשליחה.
- **אירועים** - אילו אירועים שולחים (לדוגמה: `broadcast.created`, `equipment.assigned`).
- **סטטוס** - פעיל / כבוי.
- **שגיאות אחרונות** - אם יש.
- **פעולות**: "ערוך" / "כבה" / "מחק".

**+ Webhook חדש** - כפתור בראש.

### לשונית 3: אינטגרציות מובנות

כרטיסים של אינטגרציות זמינות:

- **Vizrt** - שליחת גרפיקה לאוויר.
- **LiveU** - ניהול אנקודרים.
- **SRT Sources** - מקורות SRT.
- **MQTT** - מעקב חי של ציוד.
- **Slack / Teams** - התראות לערוצי תקשורת.

לכל אינטגרציה: סטטוס (פעיל / לא מוגדר), כפתור "הגדר" / "ערוך".

## כל פעולה צעד-אחר-צעד

### פעולה 1: יצירת מפתח API חדש

**מסך:** לשונית "API Keys" → "+ צור מפתח חדש".

**צעדים:**

1. לחצו **+ צור מפתח חדש**.
2. ייפתח חלון:
   - **שם** (חובה) - מתאר את השימוש (לדוגמה: "Slack Bot").
   - **הרשאות** - בחרו: READ_ONLY / READ_WRITE / ADMIN.
   - **תאריך תפוגה** (אופציונלי) - אבטחה נוספת.
3. לחצו **צור**.
4. **חשוב מאוד:** המפתח המלא מוצג **פעם אחת בלבד**. העתיקו אותו מיד לאפליקציה שאתם רוצים לחבר. לאחר סגירת החלון - לא תוכלו לראות אותו שוב, רק את הקידומת.
5. שמרו במקום בטוח (Password Manager).

### פעולה 2: ביטול מפתח API

**מסך:** לשונית "API Keys" → כפתור "בטל" אדום.

**צעדים:**

1. לחצו **בטל** בשורת המפתח.
2. ייפתח דיאלוג אישור.
3. אשרו - המפתח יושבת. כל בקשה אליו תיכשל.

**חשוב:** ביטול הוא קבוע. אם הייתם זקוקים שוב - תיצרו חדש.

### פעולה 3: יצירת Webhook

**מסך:** לשונית "Webhooks" → "+ Webhook חדש".

**צעדים:**

1. לחצו **+ Webhook חדש**.
2. ייפתח טופס:
   - **שם** (חובה).
   - **URL** (חובה) - לדוגמה: `https://my-server.com/lancelot-hook`. חייב להיות HTTPS.
   - **אירועים** (multi) - בחרו אילו אירועים:
     - `broadcast.created`, `broadcast.updated`, `broadcast.deleted`
     - `equipment.assigned`, `equipment.returned`
     - `shift.assigned`, `shift.swapped`
     - `user.created`, `user.disabled`
     - `workflow.completed`, `workflow.rejected`
   - **Secret** (אופציונלי) - מחרוזת לאימות חתימה (HMAC).
   - **Retry On Failure** - האם לנסות שוב אם השליחה נכשלה.
3. שמרו.
4. הוובהוק יישלח כ-POST JSON לכתובת בכל פעם שהאירוע יקרה.

### פעולה 4: בדיקת Webhook (Test)

**מסך:** לשונית "Webhooks" → כפתור "בדוק" בשורה.

**צעדים:**

1. לחצו **בדוק**.
2. המערכת תשלח אירוע בדיקה (`webhook.test`) לכתובת.
3. תוצג תוצאה: ✓ הצלחה (קוד 200) / ✗ כישלון (קוד אחר + הודעת שגיאה).

### פעולה 5: הגדרת Vizrt

**מסך:** לשונית "אינטגרציות מובנות" → כרטיס Vizrt → "הגדר".

**צעדים:**

1. לחצו על הכרטיס.
2. ייפתח טופס:
   - **כתובת השרת** (Viz Engine URL).
   - **פורט**.
   - **שם משתמש / סיסמה** (אם נדרש).
   - **תיקיית סצנות**.
3. שמרו.
4. בדקו חיבור - **"בדוק חיבור"**.

ראו `apps/web/src/app/vizrt-graphics/` לדוגמאות שימוש.

### פעולה 6: עריכת / מחיקת Webhook

**מסך:** טבלת Webhooks → "ערוך" / "מחק".

**צעדים:**

1. בשורת Webhook, לחצו על הפעולה הרצויה.
2. ערוך - פותח אותו טופס עם הערכים הקיימים.
3. מחק - דורש אישור.

## טעויות נפוצות ופתרונן

- **בעיה:** "Webhook לא מגיע למערכת היעד".
  **פתרון:** השתמשו ב"בדוק" כדי לראות אם השליחה הצליחה. בדקו ש-URL נכון ושהשרת זמין. בדקו שאין חומת אש.

- **בעיה:** "המפתח API לא עובד אצלי".
  **פתרון:** ודאו שאתם משתמשים בכותר `Authorization: Bearer <key>`. ודאו שלמפתח יש את ההרשאה המתאימה לפעולה.

- **בעיה:** "לא שמרתי את המפתח ועכשיו אני לא רואה אותו".
  **פתרון:** אי אפשר לראות שוב. תצטרכו ליצור מפתח חדש ולעדכן את האפליקציה.

- **בעיה:** "אינטגרציית Vizrt לא מתחברת".
  **פתרון:** בדקו עם רשת ה-IT שיש קשר בין שרת Lancelot ל-Viz Engine. ודאו פורט פתוח.
