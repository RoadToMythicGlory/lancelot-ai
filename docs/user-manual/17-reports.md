# דוחות - סיכומים, אנליטיקה וייצוא

> **בעמוד "דוחות" תוכלו ליצור דוחות מסכמים על שידורים, משמרות, ציוד, משתמשים, זכויות וניתוח עלויות.**
> הדוחות מאפשרים לקבל תמונה רחבה של פעילות הארגון, וניתן לייצא אותם ל-CSV / Excel / PDF.

---

## מתי משתמשים בזה?

- בסוף חודש - להכנת דוח חודשי להנהלה.
- לפני פגישת תקציב - לראות עלויות ציוד / שעות עבודה.
- לחקור היכן נמצאים צווארי בקבוק (ציוד שלא בשימוש, עובדים בשעות נוספות).
- לתקופת ביקורת חשבונאית - לייצא דוחות לרגולטור.

## איך נכנסים?

1. הדף הוא `/reports` (אם זמין בארגון - תלוי בתוכנית).
2. ייתכן שתמצאו כניסה דרך הסיידבר תחת **מערכת**.

הרשאה נדרשת: `REPORTS_VIEW`.

## מסכים ותתי-מסכים

### 1. כותרת ובחירת דוח

- **כותרת**: "דוחות".
- **רשימת דוחות זמינים** - כרטיסים גדולים:
  1. **סיכום שידורים** - שידורים שבוצעו בתקופה.
  2. **ניצולת משמרות** - אחוז ניצולת, שעות נוספות, מילואים.
  3. **שימוש בציוד** - מה היה בשימוש, כמה.
  4. **פעילות משתמשים** - לוגינים, פעולות עיקריות.
  5. **סקירת זכויות** - זכויות פעילות, פגות בקרוב.
  6. **ניתוח עלויות** - עלויות מצרפיות (ציוד + שעות + זכויות).

### 2. אזור הדוח

אחרי בחירה - מופיע:

- **סלקטור טווח תאריכים** - שבועי / חודשי / רבעוני / שנתי / מותאם.
- **סלקטור מחלקה** (אם רלוונטי).
- **גרף** - תצוגה ויזואלית.
- **טבלת נתונים** - הפרטים.
- **כפתורי ייצוא** - CSV / PDF.

---

## כל פעולה צעד-אחר-צעד

### פעולה 1: יצירת דוח סיכום שידורים

**מסך:** דף הדוחות → כרטיס "סיכום שידורים".

**צעדים:**

1. לחצו על כרטיס **סיכום שידורים**.
2. הזינו טווח תאריכים (לדוגמה: "01/02/2026 - 28/02/2026").
3. (אופציונלי) סננו לערוץ ספציפי / ענף ספורט.
4. לחצו **צור דוח**.
5. יוצג:
   - **גרף**: שידורים לפי יום / לפי ערוץ.
   - **טבלה**: כל השידורים בתקופה עם פרטים.
   - **סיכום**: סך השידורים, שעות שידור, ערוצים פעילים.
6. ייצוא: לחצו **CSV** או **PDF**.

### פעולה 2: דוח ניצולת משמרות

**מסך:** דף הדוחות → "ניצולת משמרות".

**צעדים:**

1. לחצו על הכרטיס.
2. בחרו תקופה.
3. בחרו מחלקה (או "כל המחלקות").
4. **גרף**: שעות עבודה לפי עובד.
5. **טבלה**: לכל עובד - שעות מתוכננות, שעות בפועל, שעות נוספות, אחוז ניצולת.
6. ייצוא לדוח שכר.

### פעולה 3: דוח שימוש בציוד

**מסך:** "שימוש בציוד".

**צעדים:**

1. בחרו תקופה.
2. **גרף**: 10 הפריטים הנפוצים בשימוש.
3. **טבלה**: לכל פריט - כמה פעמים הוקצה, אחוז זמן בשימוש, ערך גנוב/אבד.
4. **גילוי**: פריטים שלא היו בשימוש כלל - מועמדים למכירה / החזרה לספק.

### פעולה 4: דוח פעילות משתמשים

**מסך:** "פעילות משתמשים".

**צעדים:**

1. בחרו תקופה.
2. **טבלה**: לכל משתמש - מספר התחברויות, פעולות עיקריות, חוסר פעילות (לא התחבר X זמן).
3. שימוש: לאיתור משתמשים לא פעילים שניתן להשבית.

### פעולה 5: דוח סקירת זכויות

**מסך:** "סקירת זכויות".

**צעדים:**

1. בחרו תקופה.
2. **גרף**: עלות זכויות לפי קטגוריה.
3. **טבלה**: זכויות פעילות + פגות בקרוב + פגות.
4. שימוש: לתכנון חידושים.

### פעולה 6: דוח ניתוח עלויות

**מסך:** "ניתוח עלויות".

**צעדים:**

1. בחרו תקופה.
2. **גרף עוגה**: התפלגות עלויות בין קטגוריות (זכויות, שעות עבודה, ציוד, וכו').
3. **טבלה**: סך מצטבר.
4. ייצוא לדוח כספי.

### פעולה 7: ייצוא דוח

**מסך:** ראש כל דוח → כפתורי ייצוא.

**צעדים:**

1. אחרי שיצרתם דוח, לחצו על אחד מהכפתורים בראש:
   - **CSV** - לטבלאות.
   - **Excel** - עם עיצוב.
   - **PDF** - לדפוס / שיתוף.
2. הקובץ יורד למחשב.

## טעויות נפוצות ופתרונן

- **בעיה:** "הדוח ריק - אין נתונים".
  **פתרון:** ודאו שבחרתם תקופה שיש בה נתונים. ייתכן שאתם בארגון חדש שאין בו עדיין היסטוריה.

- **בעיה:** "הייצוא תקוע / כושל".
  **פתרון:** דוחות גדולים יכולים לקחת זמן. חכו דקה. אם זה ממשיך - בקשו תקופה קצרה יותר.

- **בעיה:** "המספרים בדוח שונים מאלה שאני רואה במודולים".
  **פתרון:** דוחות מתעדכנים מעת לעת. ייתכן שיש דיליי של עד שעה. רעננו או חכו.
