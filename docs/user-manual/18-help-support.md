# מרכז עזרה - איך משתמשים במאמרים, פניות תמיכה ולוג שינויים

> **מרכז העזרה (`/help`) הוא נקודת המוצא הראשונה כשנתקלים בבעיה, רוצים ללמוד מודול חדש, או לראות מה התעדכן במערכת.**
> בעמוד הזה תמצאו מאמרי עזרה (אותו תוכן שיש בקבצי ה-MD בתיקייה `docs/user-manual/`), פניות תמיכה שפתחתם, ו-Changelog של מה חדש בכל גרסה.

---

## מתי משתמשים בזה?

- כשאתם לא יודעים איך לעשות משהו - חפשו מאמר.
- כשמשהו לא עובד ואתם רוצים לדווח - פתחו פנייה.
- כדי לראות אילו תכונות חדשות נוספו לאחרונה.
- (מנהל) לרענן את בסיס הידע של ה-AI אחרי עריכת מאמרים.

## איך נכנסים?

1. בסיידבר, תחת **מערכת**, לחצו על **עזרה** (אייקון סימן שאלה).
2. תועברו ל-`/help`.

הרשאה: פתוח לכולם.

## מסכים ותתי-מסכים

### כותרת

- **כותרת**: "מרכז עזרה ותמיכה".
- **תיאור**: "מאמרי עזרה, פניות תמיכה ולוג שינויים".
- **כפתור "רענן בסיס ידע של AI"** - מופיע רק אם יש לכם `SETTINGS_MANAGE`. טוען מחדש את מאמרי העזרה לזיכרון של ה-AI אחרי שעדכנתם תוכן.

### לשוניות (Tabs)

#### לשונית 1: מאמרי עזרה

- **שורת חיפוש** - "חיפוש מאמרים..." - חיפוש לפי כותרת / תוכן.
- **רשימת קטגוריות נפתחת** - תחילת עבודה / שידורים / MCR / משמרות / מחסן / צ'אט / AI / ניהול / חיוב / API / פתרון בעיות.
- **רשת מאמרים** - כרטיסים 3 בשורה:
  - **תגית קטגוריה** כחולה.
  - **כותרת**.
  - **תקציר** (excerpt).
  - **N צפיות** + כפתורי דירוג: 👍 / 👎.
  - לחיצה על כרטיס פותחת מודאל עם התוכן המלא (תכלה ב-Modal לקריאת מאמר מלא).

#### לשונית 2: פניות תמיכה

מציג רק את הפניות שלכם:

- **N פניות פעילות** (Badge על הלשונית).
- **כפתור "+ פנייה חדשה"** (כחול ראשי).
- **רשימת פניות**:
  - מספר פנייה + נושא.
  - Badge סטטוס: פתוח / בטיפול / ממתין לתגובתך / ממתין לתמיכה / נפתר / סגור.
  - תאריך יצירה.
- לחיצה על פנייה פותחת מודאל עם כל ההודעות בשרשור.

#### לשונית 3: מה חדש (Changelog)

ציר זמן (Timeline) של עדכוני גרסה:

- **גרסה** (Tag כחול): v1.5.2
- **כותרת**.
- **תאריך פרסום**.
- **רשימת שינויים**, לכל אחד:
  - תגית: תכונה חדשה (ירוק) / שיפור (כחול) / תיקון (כתום) / שינוי שובר (אדום).
  - תיאור.

## כל פעולה צעד-אחר-צעד

### פעולה 1: חיפוש מאמר

**צעדים:**

1. בלשונית "מאמרי עזרה", הקלידו בשורת החיפוש - לדוגמה: "איך לרשום ציוד".
2. הרשת תסתנן לזמן אמת.
3. (אופציונלי) בחרו קטגוריה ברשימה הנפתחת לסינון נוסף.
4. לחצו על כרטיס לקרוא את המאמר.

### פעולה 2: דירוג מאמר

**צעדים:**

1. בתחתית כרטיס המאמר, יש 2 כפתורים: 👍 ו-👎.
2. לחצו על אחד - הדירוג נשמר.
3. עוזר לצוות המוצר להבין איזה מאמרים שימושיים.

### פעולה 3: פתיחת פנייה לתמיכה

**מסך:** לשונית "פניות תמיכה" → "+ פנייה חדשה".

**צעדים:**

1. לחצו **+ פנייה חדשה**.
2. ייפתח טופס:
   - **נושא** (חובה) - תיאור קצר.
   - **קטגוריה** - באג / בקשת תכונה / שאלה / חיוב / טכני / אחר.
   - **עדיפות** - נמוכה / רגילה / גבוהה / דחופה.
   - **תיאור** (חובה) - כל הפרטים. ככל שיותר טוב.
3. לחצו **שלח פנייה**.
4. תקבלו מספר פנייה. צוות התמיכה יענה בלשונית "פניות תמיכה".

### פעולה 4: מעקב אחר פנייה קיימת

**צעדים:**

1. בלשונית "פניות תמיכה", לחצו על הפנייה.
2. ייפתח מודאל עם:
   - סטטוס + קטגוריה.
   - שרשור ההודעות (כחול = תמיכה, אפור = אתם).
3. אם הסטטוס "ממתין לתגובתך" - הוסיפו הודעה ותגובה תועבר לתמיכה.

### פעולה 5: קריאת לוג שינויים

**צעדים:**

1. עברו ללשונית **מה חדש**.
2. תראו את כל הגרסאות מהחדשה לישנה.
3. סקרו את התכונות החדשות / התיקונים.

### פעולה 6: רענון בסיס הידע של AI (מנהל בלבד)

**מסך:** כפתור "רענן בסיס ידע של AI" בפינה השמאלית-עליונה.

**צעדים:**

1. אחרי שעדכנתם / הוספתם מאמרים בעזרה - לחצו על הכפתור.
2. המערכת תטען את כל המאמרים החדשים לבסיס הידע של ה-AI.
3. תוצג הודעה: "סיום: N מסמכים נטענו ל-AI".
4. עכשיו ה-AI יוכל לענות על שאלות גם על תכונות חדשות.

## איך המאמרים נכנסו למערכת?

המאמרים שלכם נטענים אוטומטית מהקבצים בתיקייה `docs/user-manual/` באמצעות סקריפט Seed:

```bash
cd services/api-gateway
npm run seed:help
```

הסקריפט קורא כל קובץ `.md` בתיקייה, חולץ את הכותרת, התקציר ("Quote" הראשון), והתוכן המלא, ומכניס למסד הנתונים כ-`HelpArticle`.

הקטגוריה של כל מאמר נקבעת לפי המספר בשם הקובץ:
- 01 → `getting_started`
- 02 → `getting_started`
- 03 → `admin`
- 04 → `shifts`
- 05, 06 → `broadcast`
- 07 → `mcr`
- 08 → `warehouse`
- 09, 10, 11 → `admin`
- 12 → `chat`
- 13 → `admin`
- 14 → `billing`
- 15 → `admin`
- 16 → `api`
- 17 → `admin`
- 18 → `getting_started`
- 19 → `troubleshooting`
- 20 → `admin`

(זה מותאם למיגרציה שלנו של קטגוריות מצומצמות.)

## טעויות נפוצות ופתרונן

- **בעיה:** "אין מאמרים".
  **פתרון:** ייתכן שלא הופעל הסקריפט `seed:help`. מנהל IT - הריצו: `cd services/api-gateway && npm run seed:help`.

- **בעיה:** "פתחתי פנייה ולא קיבלתי תשובה".
  **פתרון:** עדיין מטופלים. ההתחייבות לתגובה תלויה בעדיפות. אם דחוף - פנו בטלפון.

  **פתרון:** מנהל - הריצו "רענן בסיס ידע".
