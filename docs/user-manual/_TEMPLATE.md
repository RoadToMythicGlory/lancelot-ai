# שם המודול

> **תקציר של 2-3 שורות שמתאר את המודול במילים פשוטות.**
> השורה הזו תוצג ככרטיס במרכז העזרה הפנימי (`/help`) ככה שמשתמש שמחפש "איך לעשות X" יזהה את המודול הנכון מבלי לפתוח את המאמר.

---

## מתי משתמשים בזה?

תיאור קצר של המצבים בהם המשתמש יזדקק למודול הזה. דוגמה: "כשרוצים לתכנן שידור חדש לטלוויזיה", "כשרוצים לבדוק איזה ציוד יצא מהמחסן".

## איך נכנסים?

1. בסיידבר הימני, לחצו על **שם הלחצן** (אייקון: שם האייקון).
2. תועברו לכתובת `/route-name`.
3. אם הכפתור לא מופיע - אין לכם הרשאה. ראו את סעיף "הרשאות נדרשות" למטה.

## מסכים ותתי-מסכים

תיאור של כל אזור במסך, מלמעלה למטה ומימין לשמאל:

- **אזור 1 (למשל "כותרת הדף"):** מה מוצג, מה אינטראקטיבי.
- **אזור 2 (למשל "סרגל חיפוש"):** איזה שדות יש, מה כל אחד עושה.
- **אזור 3 (למשל "טבלת התוצאות"):** איזה עמודות מוצגות, איך ממיינים, מה קורה בלחיצה על שורה.
- וכן הלאה.

## כל פעולה צעד-אחר-צעד

### פעולה 1: שם הפעולה (לדוגמה "יצירת רשומה חדשה")

**מסך:** איפה הפעולה נמצאת (לדוגמה: "כפתור 'הוסף' כחול בפינה השמאלית העליונה").

**צעדים:**
1. צעד ראשון - תיאור מדויק.
2. צעד שני - תיאור מדויק.
3. ייפתח חלון/מסך **שם החלון**.
4. מלאו את השדות:
   - **שדה 1** (חובה / אופציונלי) - הסבר מה לכתוב + דוגמה.
   - **שדה 2** (חובה / אופציונלי) - הסבר + דוגמה.
5. לחצו על **שם הכפתור** (לרוב כחול בתחתית החלון).
6. תוצאה צפויה: מה אמור לקרות (הודעת הצלחה, רענון רשימה, וכו').

**שגיאות אפשריות:**
- "הודעת שגיאה X" - משמעות וכיצד לתקן.
- "הודעת שגיאה Y" - משמעות וכיצד לתקן.
