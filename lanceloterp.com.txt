# Prompt for Building Lancelot ERP Landing Page

## Overview
Create a modern, professional landing page for Lancelot ERP - a comprehensive broadcast management solution for TV channels, YouTube channels, Twitch streamers, and any professional broadcasting operation.

## Goal
Build a sleek tech company landing page that showcases Lancelot as a flexible, scalable ERP solution for the broadcasting industry. The site should feel like a modern SaaS product presentation.

## Target Audience
- TV Channel Executives
- YouTube Channel Managers
- Twitch Stream Operations
- Broadcasting IT Directors
- Media Production Companies
- Content Creation Studios
- Any professional broadcasting operation

## Technical Requirements

### Technologies
- Pure HTML/CSS/JavaScript (No Next.js server needed)
- OR React with Create React App / Vite (client-side only)
- Tailwind CSS for styling
- GSAP for smooth animations
- Vanilla JavaScript or React for interactivity
- Fully responsive design
- Single Page Application (SPA)

### Language
- English only
- Professional tech industry copy
- Clean, modern design language

## Design & UX Guidelines

### Color Palette
- Primary: Deep Blue (#0066CC) - Trust and professionalism
- Secondary: Vibrant Purple (#6B46C1) - Innovation and creativity
- Accent: Bright Green (#10B981) - Success and growth
- Neutrals: Grays (#F3F4F6 to #111827)
- Background: Off-white (#FAFAFA)

### Typography
- Headlines: Inter or Poppins (modern, clean)
- Body text: Inter or System fonts
- Monospace: Source Code Pro (for technical elements)

### Visual Style
- **Modern & Clean**: Lots of whitespace, minimal design
- **Glass-morphism**: Subtle glass effects on cards
- **Gradients**: Smooth gradients for backgrounds
- **Shadows**: Soft shadows for depth
- **Icons**: Line icons, consistent style
- **Illustrations**: Abstract, geometric patterns

### Animations (GSAP)
- **Hero Section**: Floating dashboard elements
- **Scroll Triggers**: Fade in content on scroll
- **Hover Effects**: Smooth scale and color transitions
- **Loading States**: Skeleton screens
- **Micro-interactions**: Button clicks, form inputs
- **Parallax**: Subtle background movements

### Component Examples

#### Navigation
- Sticky header with blur backdrop
- Smooth scroll to sections
- Mobile hamburger menu with slide animation

#### Cards
- Hover lift effect
- Gradient borders
- Icon animations on hover

#### Buttons
- Primary: Solid background with hover glow
- Secondary: Outline with fill on hover
- CTA: Animated gradient background

## Technical Implementation Notes

1. **Performance First**
   - Lazy load images
   - Optimize animations for 60fps
   - Minimal JavaScript bundle
   - CDN for assets

2. **Responsive Design**
   - Mobile-first approach
   - Breakpoints: 640px, 768px, 1024px, 1280px
   - Touch-friendly interactions

3. **Accessibility**
   - Keyboard navigation
   - Screen reader support
   - High contrast mode
   - Focus indicators

4. **SEO Optimization**
   - Semantic HTML
   - Meta tags
   - Schema markup
   - Fast loading times
